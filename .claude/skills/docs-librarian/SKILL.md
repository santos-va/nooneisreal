# Docs librarian (T7 Кліо)

## Правила
- Кожна сторінка: заголовок H1, тіло, `## Related` з ≥ 2 wikilinks. Лінк — `[[ім'я-файлу-без-.md]]` (унікальне в docs/**).
- Нова сторінка → рядок у `docs/index.md` (карта) і лінк із сусідніх сторінок.
- Кожна сесія, що щось змінила/вирішила → `docs/Meetings/YYYY-MM-DD-<slug>.md` за `_template.md`: що обговорили · що вирішили · що відклали · дії.
- Рішення → `docs/Decisions/ADR-NNN-<slug>.md` (статус, рішення, чому, чим платимо, Related).
- Факт лору з чату → `docs/World/Lore.md` або сторінка персонажа того ж дня з посиланням на журнал.
- Ассет → `docs/Art/Textures-Registry.md` (на диску з `game/assets/…`; заплановане — без префікса).
- `docs/system/state.md`: шапка «Оновлено», «Фаза», «Зараз важливо» ≤ 5 пунктів, «Що працює (виміряно …)», «Відкрите». Мутують T1/T2 у межах повноважень.
- Мова — українська; імена файлів — латиниця/цифри/дефіс.

## Перевірка
`make gates-docs` → ВІК (wikilinks) і РЕЄ (реєстр) зелені, останній рядок «ДОКИ ЗЕЛЕНІ; КОД НЕ ВИМІРЯНО». Биті лінки лагодити одразу — не «потім».
