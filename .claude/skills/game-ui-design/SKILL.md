# Game UI для No One Is Real (T8 Гермес)

## Правила, що не обговорюються
1. Усі ресурси гравця — на одній фіксованій горизонтальній смузі (HP · піпси раундів · метр · заряди гарпуна · кулдауни). Нічого не їздить під час бою.
2. Плашки пласкі з косим зрізом; фон Kronshift деталізований, тому UI — спокійний. Палітра з [[Style-Guide]].
3. Текст: критичний ≥ 20–22 px @1080p (на ТБ з 2 м), масштаб 100–200 %. Шрифт із великим x-height.
4. Тач: цілі 44 pt/48 dp, відступи 8 dp, у дузі великого пальця; віртуальний стік зліва (Godot 4.7 `VirtualJoystick`).
5. Safe area з інсетів пристрою (`DisplayServer.get_display_safe_area()`, перерахунок під `canvas_items` stretch); на ТБ — 5 % title-safe.
6. Гліфи за останнім пристроєм вводу (deadzone проти дрейфу стіка): Kenney Input Prompts / Xelu (CC0).
7. Піпси раундів — дискретні позначки, не серця; відмова ресурсу (0 зарядів) — тряска + звук за 2–3 кадри.

## Нестандартне, але зручне — як робити
- Концепт «дошка Kronshift»: косі теракотові смуги, вирізки карток на кислотно-жовтому, брашовий леттеринг анонсів.
- Навігація фокусом (стрілки/стік/Tab), ←/→ перемикає значення на місці, без вкладених меню; Esc/B — назад завжди.
- Вибір персонажа — 2D-сітка (D-pad-дружня), картка з 3 панелями скілів праворуч, лор одним рядком.
- Пауза/результат — панелі по центру з 2–3 діями, перша в фокусі.
- Тренування: frame meter, хітбокси (Tab), запис/відтворення 3 слоти, скидання (Backspace), override зарядів.
