# No One Is Real

3D-файтинг із мальованою Sketch-Cel подачею на Godot 4.7 · GDScript. Choko і Skea мають
різні бойові стилі, вільний рух, комбінації кінцівок і гарпуни. Розвиваємо Cronshift як
спільний світ; зараз доступні арени та окремий прохідний прототип міського кварталу.

**Вікі:** [docs/index.md](docs/index.md) · **поточний стан:** [docs/system/state.md](docs/system/state.md) ·
**закон:** [docs/system/constitution.md](docs/system/constitution.md) · **ролі:** `make roles`.

## Запустити на Mac

Встановіть [Godot 4.7-stable](https://godotengine.org/download/macos/) у `/Applications`,
клонуйте репозиторій і виконайте з його кореня:

```bash
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot make check
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot make run
```

У меню: **FIGHT** — CPU-суперник, **VERSUS** — двоє гравців, **TRAINING** — тренування,
**EXPLORE CITY · PROTOTYPE** — прогулянка обраним героєм. Місто має дахи, рампи,
міст і зачепи, а поточна гілка — 12 постійних NPC з розмовами й збереженням. Міські бої, повна сюжетна кампанія та портали ще не реалізовані.
Відсутні зареєстровані вихідні ассети можна відновити через `bash tools/fetch_assets.sh`;
наявні файли скрипт пропускає. Доступність зовнішнього CDN залежить від середовища.

## Керування

Стандартний профіль **SOLO**, вільний 3D-рух:

| дія | клавіші |
|---|---|
| Рух / огляд | `WASD` / утримувати праву кнопку миші й рухати мишу |
| Стрибок / присід / блок | `Space` / `X` / `L` або `F` |
| Ліва / права рука | `J` / `K` |
| Ліва / права нога | `M` / `,` |
| Ухилення / спеціальний деш / меч Choko | `Shift` / `Alt` / `V` (дістати, потім змінити руку) |
| Гарпун до ворога / паркур | `Q` / `E` |
| Навички / ультимейт | `U` або `R`, `I` або `T` / `O` або `C` |
| Розмова / відчеплення | `G` / `Z` |

На причепленій мотузці утримуйте `Space`, щоб підтягнутися; для підйому наблизьтесь
під зачіп. Захват фіксується після натискання E; повтор E обирає наступну опору, Z або ухилення відчіплює. У міському прототипі навички,
ультимейти й ворожий гарпун недоступні. `Esc` — пауза; в арені `Tab` — хітбокси,
`Backspace` — скидання позицій у тренуванні. Профіль **SHARED** і геймпади мають іншу
розкладку: актуальні підказки відображаються в грі;
[повна матриця](docs/GDD/05-Platforms-Input.md).

Музичний програвач і вирівнювання гучності готові, але три Santos Soundtracks ще потребують доступних вихідних файлів. NPC — початковий збережуваний зріз; локальна мовна модель не підключена.

## Перевірки

- `make check` — імпорт, парсинг GDScript і завершений headless smoke бою.
- `make check-playable` — попередня перевірка та регресії керування, бою, UI, мотузок і міста, з негативними контролями.
- `make gates` — посилання вікі, реєстр ассетів, ролі, структура state/планів і парсинг GDScript; потребує Godot, без нього червона (GDS → rc=2).
- `make gates-docs` — те саме без парсингу GDScript, для правок лише в документах; останній рядок «ДОКИ ЗЕЛЕНІ; КОД НЕ ВИМІРЯНО».

Godot запускайте послідовно на одному checkout. Headless-тести не замінюють огляд
рендера, слухове приймання чи перевірку керування й продуктивності на MacBook Air M3.
[Команди запуску](docs/Tech/Build-and-Run.md) · [методика тестування](docs/Tech/Testing.md).

## Структура та напрям

| шлях | призначення |
|---|---|
| `game/` | сцени, скрипти, шейдери, дані персонажів і зареєстровані ассети |
| `docs/` | поточний стан, плани, GDD, арт, світ, рішення й історія перевірок |
| `roles/` | спільні ролі агентів; клієнтські адаптери окремі |
| `tools/` | гейти, регресії, захист запуску, відновлення ассетів |

Чинний художній орієнтир міста — найсвіжіші обрані окремі текстури/вирізки Higgsfield;
старі панорами — чернетки. Бойові числа й частина анімацій залишаються прототипними.
Поточні обмеження й незавершені напрями — у
[Remaining-Work](docs/Handoff/2026-10-04-Remaining-Work.md) та [Roadmap](docs/Roadmap.md).
