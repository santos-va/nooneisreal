## Що є зараз (виміряно в цій сесії)

**Трек.** Файл Santos — `44d78d41-308_i_could_better.mp3`.
- `ffprobe` → 83.35 с, 48 kHz, стерео, 320 kb/s.
- `ffprobe -show_entries format_tags` → тегів немає. Автор — **Santos**, трек написаний в Ableton («в ебліку»), зі слів
  Santos 2026-10-03.
- **Джерело в репо:** `tools/audio/sources/skea_ult_i_could_better_57-74s.mp3`.
  - Це вікно 57–74 с, вирізане без перекодування: `ffmpeg -ss 57 -to 74 -c copy` → 17.016 с, 320 kb/s, 682 KB.
  - 0 с вікна ≈ 57.0 с треку, ±0.03 с (межа mp3-кадру).
  - Перевірка: дроп у вікні на 3.08 с → 60.08 с треку.
  - Повний трек у репо не кладемо: грі потрібне лише це вікно.

**Розмітка.** Отримав T1 так: `ffmpeg` (моно, 8 kHz) → `numpy` + `scipy`, RMS діапазону < 120 Hz вікнами 0.1 с і 0.01 с.
Межі на слух має підтвердити T6.

| відрізок | що звучить | рівень |
|---|---|---|
| 57.0–58.9 с | майже тиша | full −40…−58 dB |
| **59.0–60.0 с** | тихий підхват без басу, «вдих» | full ≈ −31 dB, sub < −76 dB |
| **60.05 с** | **дроп: вдаряє бас** | sub з −73 до −11 dB за 0.15 с |
| **60.05–70.5 с** | **партія басу 1**, 10.45 с | sub −3…−11 dB |
| 70.5–71.9 с | бас зникає, лишається середина: брейк 1.4 с | sub ≈ −28 dB, full ≈ −14 dB |
| 71.9–83.35 с | партія басу 2, файл обривається на повній гучності | останні 0.5 с: full −5.8 dB |

**Темп.** Автокореляція онсетів на 60–83 с дає період 0.36 с, тобто ≈ 166.7 BPM, або 83.3 у половинному темпі. Це
**оцінка** з точністю ±0.005 с на долю. Такт із 4 доль триває ≈ 1.44 с. Від 60.05 с до 70.5 с ≈ 7.25 такту; брейк — кінець
8-го.

**Рівень.** Трек зведений дуже гучно: RMS у вікні 0.5 с сягає −3.6 dBFS. Музика за [[07-Audio]] має стояти близько
−18 dBFS, тож у грі потрібно ≈ −12…−14 dB.

**Код.**
- Ульта Skea `cursed_grimoire` у `skea.tres`: startup 12 · active 72 · recovery 14. Це 98 кадрів, 1.63 с при
  `physics_ticks_per_second=60`, `project.godot:224`.
- `GrimoireFx.gd`: удари на кадрах `STRIKES := [36, 52, 70]`, кінець `END := 92`.
- Ульта з вуалі вже розпізнається. `Fighter.gd:627-629` у `_start_move` робить так: якщо `veil_frames > 0`, тоді
  `veil_strike = true` і `end_veil()`. Отже «дим + ульта» означає ульту, почату під SHADOW VEIL; вуаль триває 3.5 с.
- Музики в грі немає. `Sfx.gd` має лише пул SFX на шині `SFX`, без `play(from)`, без затухання і без шини `Music`.
- Звуки з паків уже в грі: `book`, `ultimate`, `time_stop`, `whoosh`… Рецепти — `tools/audio/sfx_recipes.tsv`, напр.
  `book` = page turn + «dark tone thrill», `ultimate` = «modern_cinematic_impact_022» + powerup. Сирі паки лежать
  лише на Mac (`tools/audio/nir-audio/` у `.gitignore`).

**Репозиторій.** `santos-va/nooneisreal` — **public** (`list_repos` → `"visibility":"public"`).
- Трек у git означає, що файл опубліковано, навіть без збірки.
- [[ADR-013-License-Check-At-Release]] спирається на «прототип ніхто, крім команди, не бачить». Для вмісту git це не так.
  Для чужих файлів це досі ризик: прецедент — `.gitignore:28-30`, сирі паки Sonniss. Для треку Santos ризику немає:
  автор сам дав слово.

## Розвилки

1. **Звідки трек і чи можна його в публічний git?** — **закрито (Santos 2026-10-03): трек його власний.**
   - Уривок іде в git: `game/assets/audio/music/`.
   - Рядок у [[Textures-Registry]] з автором Santos і ліцензією «власний трек Santos; використання в грі й публічному
     репо — слово Santos 2026-10-03».
   - Локальна папка й синтетична заглушка більше не потрібні.
2. **Старт.** Рекомендація: **з 59.0 с, як сказав Santos.**
   - Перша секунда — «вдих» під розкриття книги, бас вдаряє через 1.05 с (кадр 63).
   - Арес ставить удар ульти на кадр дропу.
   - Альтернатива — старт з 59.85 с, тоді дроп припадає на перший активний кадр.
3. **Що робить Skea 11.5 с довгої ульти.** Рекомендація: **«режим», а не кіно.**
   - Книга кружляє навколо Skea, Skea рухається і б'є.
   - Відбитки сторінок летять на сильні долі такту.
   - Суперник не стоїть 11 с без керування: це контргра і правило [[08-Balance]] про ульту 22–26 % HP.
   - Кінематографічне блокування на 11 с — не крок.
4. **Кінець.** Рекомендація: **обидва варіанти Santos разом.**
   - Бас у треку сам обривається на 70.5 с.
   - Цей обрив накриває **стінгер з паків**, напр. книга з гуркотом закривається.
   - Під стінгером хвіст треку затухає за 0.3–0.5 с, тож клацання немає.
   - Звичайна ульта (1.6 с) закінчується так само, лише раніше.
