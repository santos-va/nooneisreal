# Натяг мотузки й бойова індивідуальність

**Дата:** 2026-10-04 · **Роль:** T1 Дедал · **Статус:** approved
**Виріс з:** [[2026-10-04-Rope-Combat-Identity-Session]] · [[ADR-004-Physics-Is-Presentation]] · [[ADR-019-Audit-And-Many-Views-Before-Decision]]. Пряме доручення Santos реалізувати фікс і покращення.

## Що хоче Santos

Мотузка має тримати тіло, а не матилятися як макаронина. Скі — різноманітний муай-тай; Чоко — зібрана військова манера зі своєю індивідуальністю. Підхід має дозволяти різні нові персонажі.

## Аудит і погляди

Перевірено у цій сесії: `RopeVisual.gd` має 16 сегментів і 4 проходи обмежень навіть для натягнутої мотузки; `GrappleHook.drive` уже використовує кінематичний маятник з гравітацією та обмеженням довжини. `LimbMotion.gd` відрізняє героїв переважно множником 0.78 для обертання корпуса. Наявні weighted-swing, rope-visual, combat-presentation регресії. Робоче дерево на старті чисте, гілка `work`. Зовнішні PR/CI цієї сесії не перевірено. Сусідні локальні зміни розділено за власністю: grapple та fighter motion.

Вже вирішено: ADR-004 залишає влучання детермінованим, презентація не змінює frame data. Попередні бойові комбінації та finite inventory зберігаються. Нове доручення Santos знімає попередню паузу на розширення для цього вузького пакета.

| Варіант | Наслідки | Вибір |
|---|---|---|
| Лише більше damping/менша амплітуда | Дешево, але зберігає хибний slack і однакову техніку | Відхилено |
| Натяг від фізичного стану + профілі хореографії | Вага читається, наявний combat-контракт зберігається | Обрано |
| Повний rigid-body ланцюг і новий mocap pipeline | Нові залежності, ризики детермінізму/ліцензій, довший цикл | Відкладено |

| Погляд | Наслідок для рішення |
|---|---|
| Автор | Силует і манера відрізняються технікою, не швидкістю того самого кліпу |
| Новачок | Видно, коли мотузка несе вагу; повернення рук показує захист |
| Змагальний гравець | Контакт/дистанції/frame data не залежать від картинки |
| Глядач | Лікоть, коліно, поворот стегон читаються у різних фазах |
| Рушій як інша істота | Натягнута пряма не потребує нестабільної сегментної релаксації |
| Виконавець | Окремі профілі та focused тести дозволяють додавати персонажів |

Мірила: чесний бій, читабельність, Sketch-Cel, нуль платної генерації. Художнє приймання залишається за Santos після перегляду рухів.
