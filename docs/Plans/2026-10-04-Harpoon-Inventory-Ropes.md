# Гарпун: два призначення, запас, залишені мотузки й повернення

**Дата:** 2026-10-04 · **Роль:** T1 Дедал · **Статус:** `done` — уточнення Santos: Q у ворога, E для паркуру, Choko7/Skea2, повернення промаху, витягання з ударом ногою.
**База:** контрольний коміт76c4687, [[Plans/2026-10-04-Free-Movement-Limbs]], [[Research/2026-10-04-Harpoon-Aim-Rope]].

## Аудит і погляди

Перевірена основа вже має30кадрів замаху, swept-влучання,14м, утримання й керування натягнутою мотузкою. Але вона має один grapple,3заряди з таймером, не зберігає мотузки й не малює повернення промаху. Ця фаза замінює саме ці правила.

Варіанти ресурсу: A — залишити регенерацію3с, дає нескінченні залишені мотузки; B — обмежений запас7/2 з обліком кожної мотузки, обрано; C — одна універсальна мотузка, суперечить словам Santos. Припущення про відсутність таймерної регенерації явно випливає зі скінченного запасу й озвучене в роботі; максимум заданий користувачем.

Фізика: A — повний ланцюг жорстких тіл, дорогий і нестабільний; B — авторитетні swept-наконечник/довжина й обмежена сегментна декоративна мотузка з провисанням/землею/водою, обрано; C — лише пряма лінія, не відповідає відчуттю ваги. Наведення: A — лише близька ціль; B — автоматичний близький видимий кандидат плюс ручний mouse/right-stick намір, обрано; C — вільний курсор без допомоги, важко в швидкому русі.

Погляди: гравець чітко розрізняє Q/E; суперник може ухилитись/сховатись; власник запасу бачить витрату й повернення; обоє можуть використати залишену мотузку; людина з геймпадом має недвозначні Y+RT/Y+LT; повтор симуляції не залежить від декоративних сегментів; M3 обмежує число сегментів/ітерацій, цифри до вимірювання PLACEHOLDER.

## Контракт

- Q / Y+RT — ворог; E / Y+LT — паркур; I — скіл2. Старий virtual grapple лишається лише сумісним тестовим маршрутом до явно заданого режиму, фізичних колізій кнопок немає.
- Choko7, Skea2. `available + shot/recovery + deployed = capacity`. Повернення рівно один раз через token. Round reset зберігає розвішені мотузки й витрачений запас; незавершений recoverable постріл повертається при reset. New match очищає rope registry і відновлює запас.
- Parkour HANG створює match-owned мотузку; після відчеплення вона лишається, доступна обом для повторного зачеплення без нового заряду. Ліміт дорівнює сумі місткостей учасників:9 для Choko+Skea,14 для двох Choko.
- MISS_REWIND: наконечник падає, при воді тоне з опором, сегменти відстають; довжина змотування зберігається при ухиленні/оглушенні. Рух обмежений легким маневром, foot attacks не створюють дублювання заряду. Після завершення заряд повертається.
- ENEMY_EXTRACT після підтвердженого pull: руки зайняті, ноги дозволені; звичайне витягання або удар ногою синхронізує руку й повертає заряд один раз на події витягання. При kick — на першому active кадрі. Ніяких невидимих hitbox/damage змін.
- Новий постріл неможливий під час recovery. Авторитетні влучання й довжина відокремлені від декоративного Verlet; вода не вирішує damage.
- Manual aim: записуваний світовий намір гравця, видимий кандидат, перевірка від руки до цілі. Декоративна камера не підміняє intent під час replay. Автокамера лишається, ручна миша/правий стік мають пріоритет і плавне повернення. Рішення по точному UX фіксуються у GDD05/06.

## Уточнення керування після аудиту

Ручний поворот камери без оновлення напрямку нового W-жесту створює неочікуваний рух. A — лишити arena heading і лише описати обмеження; B — читати камеру щотік із Fighter, порушує відтворюваність; C — записуваний view-basis як дані вводу на початку жесту, обрано. Наявний жест тримає напрямок до нейтралі; новий бере горизонтальний basis ручного виду. CPU і SHARED без ручного виду зберігають попередній контракт. InputRouter приймає явний basis, DuelFrame фіксує його, HarpoonAim лише адаптує пристрій/вид; Fighter не посилається на Camera3D. Тести90°/180°, held-invariance, injected replay при різному рендері, UI/reset/degenerate basis. Це вузьке доповнення під початкову вимогу зручного вільного руху, погоджене T1 у межах доручення Santos.
