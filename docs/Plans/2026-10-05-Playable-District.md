# Квартал, у який є сенс повернутися

**Дата:** 2026-10-05 · **Роль:** T1 Дедал · **Статус:** `approved`
**Виріс з:** прямого доручення Santos після [[2026-10-05-City-Action-Session]]; журнал [[2026-10-05-Playable-District-Session]].

## Що хоче Santos

Видимий завершений ігровий шматок замість чергового початку системи: адаптовані до анатомії героїв бібліотечні удари й рухи; нормальна ходьба при змотуванні мотузки; доступні будівлі з інтер'єрами, працівниками, розмовами, завданнями й кастомізацією. NPC пам'ятає конкретного героя; майбутні вісім героїв відкриватимуться сюжетом. Меню і доставка мають давати змогу впізнати актуальну збірку. Контент має готувати ґрунт для модів; комерційний захист — окремий майбутній етап.

Мета досвіду — дати привід досліджувати квартал приблизно пів години. Тривалість і задоволення не підміняються числом тестів чи примусовими таймерами; їх не оголошуємо виміряними без реального проходження.

## Аудит і погляди

Факти цієї сесії: main `f24d973` містить змерджений PR #174; GitHub run `37238141104` завершив build, native macOS verify та publish успішно. Installed SHA на Mac користувача невідомий. Чинна іконка `res://icon.svg`, оригінального `app_icon.png` немає; це не доказ старої gameplay-збірки.

У `CityLayout.blocks()` будівлі переважно суцільні boxes, інтер'єрів немає. `NpcDialogue` показує факти й одну кнопку закриття, немає активних завдань або вибору. `NpcPopulation` має спільні trust/memory без hero identity. `SkeletalRig` має UAL та hero retarget, але generated LimbMoves йдуть через procedural fallback. `LocomotionCadence.choose` при швидкості Skea recovery близько 2.17 м/с обирає Jog із калібруванням близько 5.899 м/с: повільний біг замість ходьби. Наявні 254 кліпи містять punches/kick/knee/walk/jog/interact; повний перелік GLB додатково підтвердив Sprint_Enter/Sprint_Exit/Sprint_Loop: початковий пошук за Run/Start/Stop був неповним, джерела передані locomotion-смузі. Існуючі бойові таймінги лишаються authority.

Попередні рішення [[ADR-004-Physics-Is-Presentation]], [[ADR-023-City-First-Exploration]], [[2026-10-04-Living-City-Traversal]] зберігаються. Недостатність попереднього пакета зафіксована прямим user feedback, а не заперечена зеленими headless-тестами. Game Development Studio CLI відсутній; застосовується наявний native Godot/Xvfb capture, без твердження про sealed game-dev runs. Платна генерація не потрібна.

## Межі приймання

1. Три різні фізично прохідні приміщення: продуктовий магазин, кравецька, майстерня. Двері, підлога, меблі, вивіски, працівники; маршрут туди й назад без телепортації крізь тверду стіну.
2. Бібліотечні удари рук і ніг на Choko/Skea зі збереженою стороною й кадровою логікою. Native contact sheets і послідовності руху, не лише перевірка назви кліпу.
3. Ходьба під час recovery мотузки, окремі режими швидкості та керовані переходи старт/стоп. Якщо джерельного кліпу немає, стан і композиція описані чесно.
4. Осмислені локальні завдання, journal/tracker, одноразові винагороди, кастомізація, вибір реплік і персистентна дружба окремо для наявних двох героїв. Не показувати шість ще не реалізованих героїв як доступних.
5. Головне меню, HUD і pause читаються з клавіатури/геймпада; save не стирається кнопкою «нова гра» без явної дії.
6. `make check-playable`, `make gates`, цільові тести нових систем і негативні контроли; native огляд та незалежний T4 review. Mac M3 і суб'єктивне приймання не підміняти Linux.

## Чекпойнти й хендофи

Код працює в `codex/playable-district` від main `f24d973`. Агенти не комітять паралельно. Shared Godot запускається послідовно; ізольовані копії для capture/test. CityPlaces є спільним джерелом дверей/worker/landmark позицій; CityProgress має changed/summary/journal для HUD. Проміжні результати й raw evidence лежать у `/workspace/nooneisreal-evidence/playable-district/`.

CP1 — контракти й реалізація смуг; CP2 — інтегрований цикл кварталу; CP3 — візуальні виправлення й regression; CP4 — PR/доставка. Після кожного CP журнал указує HEAD, виконане, докази, блокери й наступний крок. Нові чати не створюються автоматично; продовження можливе з журналу.
