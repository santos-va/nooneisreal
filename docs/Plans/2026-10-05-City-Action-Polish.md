# Місто й екшен — усунення рецидивів

**Дата:** 2026-10-05 · **Роль:** T1 Дедал · **Статус:** `approved`
**Виріс з:** прямого доручення Santos у новій сесії T1; [[2026-10-04-Living-City-Traversal]], [[2026-10-05-City-Action-Session]].

## Що хоче Santos

Рознести NPC, оживити їхню комунікацію, зробити мотузку зручною для екшену без точного наведення камерою, поліпшити бойові анімації та поверхні міста, виправити стару іконку застосунку. Використати агентів і готові бібліотеки; передати PR для власного мерджу Santos.

## Аудит і погляди

Перевірено локальний початковий HEAD `e27b746`; GitHub main після PR #173 — `66d5353`, інтегровано fast-forward перед пакетом. Незакомічені зміни агентів збережено. Термінал користувача до цього чату не прикріплений. Оточення Linux має Godot 4.6.3; для цільової перевірки потрібен Godot 4.7. Чинний macOS updater вже в main; локальна робота не змінює встановлений застосунок користувача.

Аудит смуг: NPC мають компактну сітку й дуже малий рух; HarpoonAim обмежує camera assist вузьким конусом; перехід skeleton після процедурного удару різкий. Jolt уже підключений, UAL бібліотеки вже містять бойові кліпи. Зовнішні ліцензії й сумісність перевіряє T3. Джерело схваленої іконки описане в [[2026-10-04-Choko-App-Icon]], байти поки недоступні. Чинні ADR про presentation-only фізику та спільне місто зберігаються. CI нового пакета ще не виміряне.

| Варіант | Наслідки | Вибір |
|---|---|---|
| Лише підказки та косметика | Не усуває нерухомість і точне наведення | Відхилено |
| Виправити наявне ядро й використати наявні кліпи/матеріали | Обмежений ризик, перевірюваний результат | Обрано |
| Одразу замінити AI, фізику й систему світу сторонніми фреймворками | Міграція, нові залежності та ліцензії, більший ризик регресій | Дослідити окремо |

| Погляд | Наслідок для реалізації |
|---|---|
| Новачок | Зачіп доступний без піксельної точності |
| Гравець у швидкому русі | Напрям руху впливає на кандидата, ручний огляд зберігає намір |
| Геймпад | Видимий стабільний кандидат без постійного коригування центра |
| Мешканець міста | Власний маршрут, коротка зустріч і пам'ять замість безперервного стояння |
| Змагальний гравець | Анімаційна презентація не змінює damage/hit timing |
| Художник | Використовуються чинні Sketch-Cel матеріали й схвалена іконка |
| Власник Mac | PR передує оновленню; не заявляємо перевірку Finder/M3 з Linux |

Мірила вибору: читабельність, передбачуваний намір гравця, сталі ресурси мотузок, відсутність регресій і зайвих залежностей. Зміни поведінки прямо санкціоновані поточним дорученням; платної генерації немає.

## Хендофи і межі

Смуги мають окрему власність; спільний Godot запускається послідовно. Агенти не комітять паралельно. Перевірки в ізольованих копіях дозволені. Немає push у main, мерджу чи публікації збірок. Оригінал іконки інтегрується лише за фактичної доступності, без підміни іншим портретом.
