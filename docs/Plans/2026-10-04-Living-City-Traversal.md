# Живий район: мотузники, ухилення, музика й мешканці

**Дата:** 2026-10-04 · **Роль:** T1 Дедал · **Статус:** approved
**Виріс з:** [[2026-10-04-Living-City-Session]] · [[2026-10-04-Rope-Combat-Identity]] · [[ADR-004-Physics-Is-Presentation]] · [[ADR-019-Audit-And-Many-Views-Before-Decision]]. Реалізація авторизована прямим дорученням Santos, включно з агентами після push.

## Що хоче Santos

Три власні біти з Santos Soundtracks: один меню, два бій, однакова сприймана гучність і спокійний рівень. Прицілювання в ліхтарі, необхідна довжина мотузки, маятник, швидка заміна одноразового мотузника на наступний і ранній захват залишеної мотузки. Окремі dash і частіші ухильні стрибки зі стаміною. Зручна клавіатура/миша/геймпад та компактний зрозумілий HUD. Постійні NPC зі стабільною зовнішністю, обов'язками, пам'яттю, впливом середовища, розмовами й можливим локальним ШІ.

## Аудит і погляди

Перевірено в цій сесії: попередній фікс committed/pushed `f1c147d` у `codex/rope-combat-identity`; origin `santos-va/nooneisreal`. `GrappleHook.drive` — маятник з кінематичним обмеженням; наявний release-on-key-up незручний для повторного пострілу. `MatchRopes` зберігає розгорнуті мотузки, але потрібні ранній вибір і готовність ловити. `MainMenu`, `Arena` та `CityWorld` мають окремі entrypoints. У доступних /workspace,/home,/tmp папку Santos Soundtracks не знайдено; шлях запитано у Santos. `Lore` — канон; `PROPOSAL-Story-Arc` містить також ще не затверджені пропозиції. Нові сюжетні ідеї не переписують Lore. Інші зовнішні PR/CI не перевірено. Локальні власники файлів визначені нижче.

Вже вирішено: фізика не визначає бойове влучання; finite inventory не стає безкоштовним; seed визначає особистість NPC на створенні, а не при кожному spawn. Родинні/сюжетні імена Twelve не вигадуємо. Повний локальний LLM runtime не встановлюється мовчки й не стає обов'язковим для запуску.

| Варіант | Перевага | Ціна/рішення |
|---|---|---|
| Додати лише текст підказок і сценарні NPC | Малий ризик | Не вирішує повторний захват і постійність мешканців, відхилено |
| Механічне ядро + збережений світ + опційний LLM | Перевірювані причинність, память, керування | Обрано; прототип району, не готова вся сюжетна гра |
| Кожен NPC весь час живе через велику LLM | Непередбачувані репліки | Затримки, непослідовність і висока ціна; не основа симуляції |

| Погляд | Що змінює |
|---|---|
| Автор | Унікальні історії виникають зі збережених подій, не з випадкового тексту |
| Новачок | Один видимий кандидат захвату; існуюча мотузка не витрачає новий пристрій |
| Геймпад | Великий палець може тримати огляд; контекстні кнопки без втрати навичок |
| Змагальний гравець | Stamina/skill доступні й перевіряються input-тестами; iframe не випадковий |
| Мешканець міста | Події поза камерою не стирають пам'ять і зовнішність; не знає невідомого |
| Рушій/малопотужний ПК | Обмежений активний район; далекий стан симулюється компактно; LLM optional |
| Гравець з чутливістю до звуку | Нормалізація loudness, запас peak, окремий тихий рівень музики |

Мірила: читабельне передбачуване керування, причинність світу, не зламати вже працюючий бій, нуль платної генерації.

## Рішення керування мотузкою

Parkour attach фіксується після натискання; відпускання більше не скидає підвіс. Повтор E/L3 обирає наступну ціль, Space/A підтягує. Z у SOLO, лівий/правий Ctrl у SHARED або B на геймпаді відчіплює; dodge теж відпускає підвіс. Клавіатурне відчеплення має окремі клавіші, щоб зберегти сувору перевірку відсутності конфліктів; B контекстний. Пріоритет existing-rope catch має бути видимий і не запускати новий projectile. Це санкціонована зміна старого hold-контракту; low-level тести маятника не підміняють перевірки фактичного вводу.

## Сюжетний напрям — пропозиція T1, не новий канон

Мешканці можуть стати свідками пошуку того, хто прокляв Скі: знати лише те, що бачили, пам'ятати допомогу або зрив роботи, мати різні причини говорити. Шлях до свідка змінюється через розклад, погоду/події та довіру, але критична сюжетна інформація має запасне джерело — гравець не втрачає сюжет через одну симуляційну випадковість. Побутова подія може стати невеликим локальним дорученням; модель не вигадує завершену подію без запису рушія. Це наступний шар над нинішнім вертикальним зрізом, не обіцянка готових актів.

## Хендофи і межі

Fighter редагує тільки агент ухилення; мотузка передає йому API інтеграцію. CityWorld тільки NPC; музика просить hook. InputRouter/HUD тільки controls. Усі смуги без власних комітів; T1 перевіряє інтегрований стан. Push попереднього пакета виконаний до запуску агентів. Платні генерації/публікація/merge відсутні. Музичні файли блоковані їх фактичною доступністю, незалежна робота триває.
