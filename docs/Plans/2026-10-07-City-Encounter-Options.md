## Розвилки для Santos

1. **Суперник:** другий герой як CPU (рекомендовано, канон спарингу) чи новий ворог (тоді варіант C з артом і кредитами).
2. **Ставки:** спаринг без збереження (рекомендовано для першого кроку) чи сюжетний бій із наслідком у CityStory.
3. **Раунди:** 1 раунд (рекомендовано для міста) чи до двох перемог (`GameState.gd:43` → `rounds_to_win = 2`, за T5).
4. **Ворожий гарпун у кишені:** вимкнений у першому кроці (рекомендовано) — інакше потрібне правило для міських мотузок.
5. **NPC на час бою:** відходять за межу кишені (рекомендовано) чи стоять глядачами за бар'єром.
