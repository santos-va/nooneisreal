# Active ragdoll (Euphoria-lite)

Рішення: фізика — презентація ([[ADR-004-Physics-Is-Presentation]]). Джерело: [[2026-10-02-Engine-Physics]].

## Що є в 0.1 (`scripts/fighter/Ragdoll.gd`)

- Регдол будується у момент удару зі знімка процедурного рига (та сама поза, кольори): 11 `RigidBody3D`
  (таз, тулуб, голова, плечі, передпліччя, стегна, гомілки), капсули, маси 1.5–12, `axis_lock_linear_z`.
- Суглоби `Generic6DOFJoint3D`: лінійні осі замкнені, кутові ліміти по суглобу (лікоть/коліно — шарнір,
  плече/стегно — конус), **кутові пружини як «м'язи»** (жорсткість 55, демпфування 6) тягнуть до
  позі спокою. Через 0.9 с м'язи вимикаються — тіло «здається» перед вставанням; на KO м'язів немає одразу.
- `Fighter` у стані LAUNCHED слідує за тазом регдолу; коли тіло заспокоїлось (< 0.7 м/с 18 кадрів)
  або минуло 170 кадрів — встає (`GETUP`, 26 кадрів невразливості).
- Звичайні удари — не регдол, а **спринг-флінч** у `RigAnimator` (second-order spring 5.5 Гц, ζ 0.32)
  на тулубі/голові: дешево, детерміновано, читається.

## Стадії далі

1. **KO = повний регдол** — є.
2. **Запуск/нокдаун = регдол з відновленням** — є (капсули); на скелеті: `PhysicalBoneSimulator3D.physical_bones_start_simulation()`,
   `influence` 0→1 за 2–4 кадри, get-up за орієнтацією хребта.
3. **Реакції на удар = частковий active ragdoll** — симулювати лише вдарену кінцівку, PD-момент до пози
   анімації (`τ = Kp·θ·axis − Kd·ω` у `_integrate_forces`), `influence` 0.3–0.6 на 6–12 кадрів.
4. **Постійна м'яка вторинна анімація** — низький gain на хребті/руках; обережно, інакше не Storm.

## Jolt — що працює, що ні

6DOF: ліміти, пружини, мотори — так; `*_limit_softness`, `restitution`, `damping`, `erp` — ні.
`PhysicalBone3D` має лише ліміти (без моторів) → для «м'язів» на скелеті або PD-момент
(підхід A), або `RigidBody3D` + 6DOF-сервопружини (підхід B — те, що вже робить `Ragdoll.gd`).
