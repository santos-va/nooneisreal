# Запуск на Mac (і не тільки)

## Застосунок у /Applications

Для гри без редактора розпакуйте `NoOneIsReal-Installer.zip` і відкрийте
**Install.command**. Інсталятор показує точний SHA збірки, ставить
`/Applications/No One Is Real.app` та вмикає оновлення перевірених main-збірок
при вході й кожні 15 хвилин. Відкриту гру updater не замінює; наступна перевірка
оновить її після закриття, довантажуючи лише змінені 4 MiB-блоки та перевіряючи
точні байти нового підписаного app. Повний архів потрібен для першого встановлення. Перший пакет містить app для офлайн-встановлення,
тому доступність release-каналу не потрібна для першого запуску.

Якщо гра вже встановлена попереднім інсталятором, не потрібно завантажувати її
повністю ще раз: розпакуйте малий **NoOneIsReal-Updater.zip** та відкрийте
**Enable Updates.command**. Він лише перевірить app і встановить новий updater,
без звернення до мережі. Після появи перевіреної main-збірки оновлення прийде
автоматично; до цього канал може ще не існувати. Старий updater сумісний із
full ZIP, але довантаження блоків потребує цього одноразового оновлення updater.

Звичайний `.app` запускається без Terminal, Godot, Python або git. Права запису
в `/Applications` потрібні поточному користувачу; updater не запитує пароль
у фоні. Наявні Godot settings і NPC saves лишаються на місці. Логи updater —
`~/Library/Application Support/No One Is Real/Updater/`.
Збірка ad-hoc підписана, **не Apple-notarized**; стандартні захисти macOS
не вимикаються. Докладніше, включно з вимкненням автооновлень і межами
приймання M3: [[Export-Platforms]]. Пакет, який ще не опублікований, не можна
вважати доступним лише через наявність workflow у репозиторії.

## Перший запуск із вихідного коду

1. Встановіть Godot **4.7-stable**: https://godotengine.org/download/macos/ → `/Applications`.
2. Клонуйте репозиторій і перейдіть у його корінь. На Linux задайте шлях до свого Godot 4.7 через `GODOT_BIN`.
3. Виконайте `GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot make check`.
4. Виконайте `GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot make run`.

`bash tools/fetch_assets.sh` відновлює відсутні вихідні ассети з реєстру, пропускаючи
наявні файли. Це не обов'язкове повторне завантаження повного checkout; доступність
CDN перевіряється в поточному середовищі, а не виводиться зі старого журналу.

## Оновлення вихідного коду

- `GODOT_BIN=… make update` — fetch, fast-forward поточної гілки та повторний імпорт.
- `GODOT_BIN=… make update BRANCH=<гілка>` — перейти на вже доступну гілку й оновити її.
- За змін у tracked-файлах або розходження гілки з origin команда відмовляє. Вона не замінює збереження власної роботи.

## Режими й керування

`make run` відкриває меню: FIGHT проти CPU, VERSUS, TRAINING та EXPLORE CITY · PROTOTYPE.
Місто запускає обраного героя для руху й паркуру та 12 постійних NPC з розмовами; міські бої, повна кампанія й портали ще не працюють. Його HUD пояснює недоступні бойові навички.

Вільний 3D-рух — початковий режим, але меню зберігає вибір. `make run-plane` явно
вмикає площинний бій. Для примусового 3D запуску: `"$GODOT_BIN" --path game -- --free-move`
після імпорту. Редактор: `make editor` або відкрити `game/project.godot`.

Актуальні клавіші — [[05-Platforms-Input]] та підказки гри. У SOLO/3D: WASD — рух,
Space — стрибок/підтягування на мотузці, Shift — ухилення зі stamina, Alt — спеціальний деш, J/K/M/кома — кінцівки, V — меч
Choko, Q/E — ворожий/паркурний гарпун. Esc — пауза; в арені Tab — хітбокси,
Backspace — скинути позиції в тренуванні. Для підйому мотузкою наблизьтесь під зачіп;
пологий трос спочатку тягне до опори. E фіксує зачіп і повторним натисканням змінює ціль; Z відчіплює. G — розмова з мешканцем.

## Перевірка й діагностика

`make check-playable` включає імпорт, парсинг, smoke і регресії. Окремо потрібен
`make gates`; деталі й native-рендер — [[Testing]]. Один checkout — один Godot за раз:
закрийте гру/редактор перед перевірками. `make run`/`make editor` імпортують кеш класів,
якщо його немає або змінився HEAD.

- **Невідомий `class_name` після checkout:** `make import`; каталог `game/.godot/` локальний.
- **Помилки autoload у ручному `--check-only`:** штатний гейт фільтрує лише відомі ідентифікатори; працездатність перевіряє smoke. Інші помилки не ігноруйте.
- **Відсутній арт:** звірте файли з [[Textures-Registry]], відновіть потрібні через fetch-скрипт і переімпортуйте.
- **Headless без звуку/пікселів:** це не слухова або візуальна перевірка; потрібен звичайний запуск із рендерером.

## Перше встановлення з локального репозиторію на Mac

`tools/distribution/install-local-macos.sh /path/to/repository <tooling-commit>`
будує повну app з `game/` саме вказаного 40-символьного commit у тимчасовій
директорії. Checkout і незакомічені правки залишаються недоторканими.
Потрібні macOS, git, доступний для запису `/Applications` та інтернет, якщо
Godot 4.7 або шаблону немає. Скрипт використовує наявний Godot 4.7; інакше
завантажує офіційний редактор у тимчасову директорію. Відсутній macOS-шаблон
потребує завантаження офіційного пакета близько **1,28 GB**. Обидва завантаження
перевіряються за офіційними SHA512. Python, Xcode та sudo не потрібні.

Після експорту штатний updater перевіряє архів, arm64, metadata та ad-hoc підпис,
встановлює `/Applications/No One Is Real.app`, вмикає оновлення і відкриває гру.
Логи збірки: `~/Library/Logs/No One Is Real/local-{import,export}.log`.
Це локальна збірка, не notarized публічний дистрибутив; глобальні налаштування
Gatekeeper скрипт не змінює. Малий `Enable Updates.command` сам гру не встановлює.
