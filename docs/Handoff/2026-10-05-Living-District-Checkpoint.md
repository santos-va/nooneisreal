# Checkpoint: мешканці, близький контакт і рух мотузки

2026-10-05 · координатор T1 · гілка `codex/living-district-characters` · кандидат **0.5.0**. База — merged #177 `f4defd5`. План [[2026-10-05-Living-District-Characters]], журнал [[2026-10-05-Living-District-Session]]. Продовжувати з цього checkpoint, не починати виконані смуги заново.

## Прийнятий зріз

- Захват на 0,70 м від поточної руки до фізичного сегмента: без прогнозованого дотягування, зі справжніми рухомими кінцями й двома перевірками видимості. Далекий промпт просить підійти; не витрачає пристрій. Дальність нового пострілу не змінена — [[2026-10-05-Rope-Contact-Range]].
- Три групи фантазійних NPC, одяг, предмети роботи й п’ять жестів. Спільні ресурси, максимум 45 мешів / 2956 трикутників на NPC. Коротке власне безсловесне звучання, максимум два голоси, слухач на герої, чинний mute — [[2026-10-05-Fantasy-Residents-And-Chatter]].
- Близькі розмови, доступні працівники, персональні теми, окрема пам’ять героїв; решта натовпу продовжує рух. Бокова панель й кадрування показують співрозмовника — [[2026-10-05-Close-NPC-Conversations]] · [[2026-10-05-Conversation-Camera]].
- Адаптовані наявні UAL для кидка, хвату, підтягування, перенесення та відпускання; довжини рук конкретних героїв враховано. Бойова й мотузкова фізика не передана анімації — [[2026-10-05-Authored-Hook-Motion]].
- Необов’язковий клієнт локального Ollama, вимкнений за замовчуванням: атмосферний текст із контексту, негайна авторська відповідь, bounded HTTP, timeout, stale guard. Модель не керує дорученнями чи нагородами — [[2026-10-05-Local-NPC-Models-And-Physics-Reuse]].

## Перевірки CP2

Повторний `make check-playable`: **70 сценаріїв / 0 помилок**, включно з усіма попередніми 62 та 12 негативними контролями; smoke **164 / 19847 кадрів**. `make gates`: **99 GDS / 0**, батарея зелена. Новий authored-hook сценарій у фінальному прогоні має **11498 / 0**, включно із завершенням змотування промаху й поверненням запасу.

Перший повний прогін 69/70 не прийнято: audio fixture чекав прискорений час симуляції замість реального mixer buffer. Тест виправлено без зміни production та послаблення вимоги звукової енергії. Повтор отримав 28672 frames для кожної проби, однаковий RMS 0.038121 при camera distance 2/6/20 м та нульову енергію поза радіусом. Попередній журнал збережено окремо. Початкові відмови sandbox/socket і guard теж не зараховані як проходження.

Незалежний [[2026-10-05-Living-District-Review]] — GREEN: 1080 кадрів обох героїв, 250 кадрів NPC-жестів та 12 actual shop conversations. Виправлені baseline/after CSV містять 1080 рядків із нульовою різницею. Перевірені SHA256 файлів native ізолятів збігаються з source. Native MISS показує обмежений відрізок змотування; повне завершення доведене runtime-тестом, не приписане короткому відео.

Основні докази поза git: `/workspace/nooneisreal-evidence/district-close/validation/`, `/workspace/nooneisreal-evidence/living-district/hook-final-v2/`, `/workspace/nooneisreal-evidence/living-residents/final-city/`. Відео `/workspace/nooneisreal-evidence/living-district/hook-before-after.mp4`: 21,2 с, 1000×550, 60 fps; додатковий повтор хвату позначений 0,5×. Компактні native PNG/JPG включені у відповідні wiki-сторінки й репозиторій.

Exact-SHA PCK, фінальні CI та PR записуються наступним checkpoint після фактичного виконання; цей розділ не оголошує їх наперед.

## Межі та наступний крок

Santos повідомив про приймання **попереднього** зрізу на M3; встановлений SHA, RAM і FPS не названі. Новий зріз потребує свого користувацького приймання. Linux/Mesa, геометричний бюджет і вимір engine audio не є M3 FPS або прослуховуванням на колонках.

Реальна мовна модель не запускалася: ваги та Reddit недоступні за enforced network policy. HTTP fixture перевіряє протокол, а не якість української генерації. Ваги не завантажуються автоматично. Точний локальний рецепт, джерела й ліцензії — у дослідженні; не обходити мережеві відмови.

Іконка незмінна до оригінального нового PNG. Мережевої гри з друзями ще немає; запитано бажаний формат, відповіді немає. Повне місто, сюжетні відкриття восьми героїв, voiced dialogue, mod SDK та юридична модель лишаються окремими майбутніми роботами. Нормальний огляд після розмови повертає ракурс користувача: віконні рами можуть знову потрапити в кадр; вільна видимість співрозмовника забезпечена для діалогу.
