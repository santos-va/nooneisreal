# No One Is Real — конституція проєкту

Спільний закон. Клієнт-нейтральний, одна копія. Адаптери (`CLAUDE.md`, `AGENTS.md`) несуть
вказівники, не текст закону. Правило живе тут, **тільки якщо має механізм** (гейт, хук,
deny-глоб або чек-лист у шаблоні); решта — практика в адаптері.

## Boot Order

1. [[state]] — поточна правда (шапка приходить хуком).
2. Ця конституція.
3. Адаптер свого клієнта (`CLAUDE.md` для Claude Code, `AGENTS.md` для інших).
4. `roles/<роль>.md` за префіксом Santos (без префікса — T1 Дедал).
5. Сторінка вікі, якої торкається задача ([[index]]).

## Канон проєкту

- Гра: 3D cel-shaded аніме-файтинг на арені. Візуал — Storm; фізика — active ragdoll,
  але **фізика ніколи не вирішує влучання** ([[ADR-004-Physics-Is-Presentation]]).
- Движок: Godot 4.7, GDScript; текстові сцени й ресурси, headless-перевірка
  ([[ADR-001-Engine-Godot]]). Код у `game/`, документація у `docs/`.
- Платформи: ПК/Mac (клавіатура) → геймпад → PS5/Xbox (через W4 Consoles) → Android/iOS.
  Один мувсет на всі пристрої: не більше 9 дій на бійця ([[05-Platforms-Input]]).
- Арт: Higgsfield (зображення), Meshy через Higgsfield MCP (3D + авториг). Кожен ассет —
  рядок у [[Textures-Registry]].

## Мова

- **Українська:** чат зі Santos, вікі, ролі, журнали, ADR.
- **Англійська:** commit-меседжі, імена файлів, ідентифікатори, коментарі в коді.

## Автономія

- **Green:** читання, пошук, `make check`, `make gates`, записи у `docs/`, дрібні правки.
- **Yellow:** зміна поведінки гри, видима гравцю; зміна чисел бою; зміна інпут-мапи.
  Пауза і наслідки перед дією, запис у ADR або в журнал.
- **Red (тільки зі словом Santos):** витрата кредитів Higgsfield; push у `main`; видалення
  ассетів; публікація збірок; зміна ліцензій.

## Тверді правила (кожне має механізм)

- **R0 Чесність і перевірка — головне правило (Santos, 2026-10-02).** Перед кожною відповіддю, де є факт
  про проєкт, ассет, кредити, модель, ліцензію чи стан коду, цей факт **перевіряється в джерелі в цій сесії**:
  файл у репо, команда, виклик інструмента (Higgsfield `balance`/`models_explore`/`get_cost`, GitHub, `make check`).
  Не перевірив — так і кажеш: «не перевірено». Не вигадуєш URL, ціни, можливості моделей, назви файлів.
  Помилку в попередній відповіді визнаєш і виправляєш першим рядком. Механізм: хук `state_header.sh`
  додає нагадування R0 до кожного промпту; Феміда (T4) перевіряє твердження командами ([[recurring_class_register]]).

- **R1 Реєстр.** Файл у `game/assets/` без рядка в [[Textures-Registry]] не проходить
  `texture_registry_check.py`.
- **R2 Wikilinks.** Биті `[[...]]` у `docs/` і `roles/` валять `wikilink_check.py`.
  Кожна сторінка закінчується `## Related`.
- **R3 Перевірка коду.** «Готово» означає зелений `make check` (headless import + парс
  усіх `.gd` + smoke-тест бою) і зелений `make gates`. `rc=2` («не зміг виміряти») блокує
  так само, як порушення.
- **R4 Журнал.** Сесія, що щось змінила або вирішила, лишає запис у `docs/Meetings/`
  того ж дня (шаблон `_template.md`) і оновлює [[state]]. Рішення — ADR у `docs/Decisions/`.
- **R5 Кредити.** Жоден `generate_*` без слова Santos у цій сесії; перед ним — `balance`
  у чат. Sub-агент Аполлона не має інструментів генерації взагалі.
- **R6 main недоторканий.** Робота йде в гілках; мерджить Santos.
- **R7 Числа з джерелом.** Кадри, фізичні константи, ліцензії, API — з посиланням
  (документація з версією або файл:рядок) або з позначкою `PLACEHOLDER` у даних.
