## Поточна реалізація T2: міські трюки та якість картинки, 2026-10-05

**Статус доставки:** перевірена локальна гілка `codex/parkour-tricks-visual-quality` на базі `abce638` (merged PR #181/#182). Нові трюки, анімації та quality settings **ще не змерджені**; встановлення цього пакета на Mac не підтверджене. Попередні CI сюжетної/документальної бази не є CI цієї хвилі.

Обидва герої виконують wall kick біля реальної вертикальної стіни: відпустити jump, рух від стіни й нове натискання; один поштовх до опори, без підзарядки climbing effort. Crouch + напрям під час достатнього падіння запускають короткий landing roll на широкій майже плоскій опорі. Перекат лише зберігає й гальмує обмежену фактичну швидкість, без bonus speed або невразливості; collision, край, lock/UI/revision, rope і пріоритет звичайних дій перевірені. Дуельний мотор і бойові числа не змінені. Підказки використовують наявні кнопки — [[2026-10-05-City-Parkour-Tricks]].

Авторські UAL `Roll` та `WallRun_Jump` читають фізичні metadata. Точна weighted skin опора й видиме спорядження коригують лише презентацію, раз на physics serial; кістки, gameplay position/velocity й sword ownership збережені. Коротка опора на спорядження під час roll прийнята як стилізована акробатика; це не гарантія контакту лише шкірою. Чинний presentation stow лишає меч на спині під час паркуру. Фінальний Linux CPU probe вузького solver: Choko median **1,039 мс**, p95 **1,689 мс**; Skea **0,973 / 2,435 мс**, без твердження про FPS — [[2026-10-05-Trick-Motion]].

Є збережувані Low/Medium/High: scale **0,75/0,85/1**, MSAA **off/2×/4×**, типовий High зберігає попередню якість. HUD лишається у вихідній роздільності; renderer, gameplay і геометрія не перемикаються. Пошкоджені graphics bytes не перезаписуються. Shader приглушує занадто дрібні wood/cloth візерунки за екранною частотою; палітра й близька фактура збережені. Це PLACEHOLDER профілі навантаження, не виміряне GPU-прискорення — [[2026-10-05-Graphics-Quality-And-Surface-Filtering]].

**Особисто перевірено T2:** фінальні raw/rc у `/workspace/nooneisreal-evidence/tricks-quality/final/` — `make check` smoke **164 / 19847 кадрів**, `make gates` **119 GDS / 0**, **175/175 assets**, `make check-playable` **93 сценарії / 0 failures**, усі rc0. Чинні case logs: motor **84/0**, legacy parkour **73/0**, незалежний tricks **54/0**, trick motion **3265277/0**, graphics **63/0**, незалежний graphics **62/0**, input UI **15/0**. Власний скан **95 engine raw logs** підтвердив **0 unexpected errors/warnings/leaks**; deliberate negative assertions відокремлені. Before/after review/playable та фактичні поточні **808 sources** тотожні, digest `c5b5d42190c355cb4b416914bed8f5941d1b57a9a7def29e8311734865b7f024`.

**Native і межі:** справжні CityWorld/CityCamera/light/HUD дали **90 PNG / 249 ticks / 0**, відкриті kick supplements — по **19 PNG / 52 ticks / 0** для обох героїв, rc0; лише відоме llvmpipe VSync warning. T6 прийняв scoped open kick/roll і оглянуті High/Low кадри; Medium окремо художньо не приймався. На тісній станції `(4,0,31.4)` камера стискається й proximity dither приховує героя: цей кут **YELLOW, художньо не прийнятий**, supplement його не виправляє. Camera code незмінний і стискання є до jump, але старого executable baseline немає — причинність не встановлена. M3/Forward+ FPS/frame-time, фізичний контролер, звук і нове Mac-встановлення не виміряні; station captures не є суцільним ручним проходженням — [[2026-10-05-Traversal-And-Surface-Review]].

Збереження сюжетів окремі від економіки й NPC. Пошкоджені байти не перезаписуються, незбережене завершення не створює стійку NPC пам’ять. Відсутній, пошкоджений або незавершений попередник призупиняє другий епізод без втрати його збережених фактів. Один вибір керує сюжетною карткою й напрямком; ручний вибір доручення та вимкнення guide збережені. Огляд предметів перевіряє фізичну дальність, видимість і власника UI; копіювання додатково перевіряє справжній промінь ліхтаря.

**Історичне приймання сюжетної бази:** перед PR #181 official Godot 4.7 дав smoke **164/19847**, gates **116 GDS/0**, **175 assets**, playable **85 сценаріїв/0**, усі rc0. До/після незмінні 793 source files, digest `0beea2abbfde9b603487a1c8aa3084f0337d3e842ab0d772d701789e09b6b32c`. Прийнято 21 фінальний native кадр нового епізоду та окремий доступний через клавіатуру журнал призупинення. Raw і точні межі — [[2026-10-05-Lower-Mark-Logic]], [[2026-10-05-Lower-Mark-Review]], [[2026-10-05-Lower-Mark-Visual]]. Той датований документальний cleanup не запускав гру повторно; чинні результати нової хвилі наведено вище.

**Доставка й апаратні межі:** є universal macOS export, installer та updater із перевіркою revision/hash і довантаженням змінених блоків; поточні команди — [[Build-and-Run]] та [[Export-Platforms]]. У [CI змердженого PR #180](https://github.com/santos-va/nooneisreal/actions/runs/37297997177) успішно завершилися docs gates, Godot smoke/playable/native compatibility та updater safety на macOS і Ubuntu; T1 особисто звірив jobs. Це hosted macOS regression, не встановлення на Santos M3. Наявність цих засобів і CI не доводить оновлення встановленого застосунку Santos. Його приймання попереднього зрізу на M3 не є виміром FPS/frame-time нового commit. Retina, фізичний контролер, звук, остаточний арт і нова Mac-збірка потребують свого приймання; реальні Santos Soundtracks ще не надані. Linux native використовує llvmpipe, а постановка на станції для кадрів не замінює суцільного ручного проходження.

Повний стан до цієї звірки збережено без зміни байтів у [[Handoff/2026-10-05-State-Before-Reconciliation]]. Старі кандидати, числові заміри й деталі доставок залишаються там та в датованих Fix/Audit; вони не є новими твердженнями про поточний PR або встановлену збірку.
