Його приймання попереднього зрізу на M3 не є виміром FPS/frame-time нового commit. Retina, фізичний контролер, звук, остаточний арт і нова Mac-збірка потребують свого приймання; реальні Santos Soundtracks ще не надані. Linux native використовує llvmpipe, а постановка на станції для кадрів не замінює суцільного ручного проходження.

Повний стан до цієї звірки збережено без зміни байтів у [[Handoff/2026-10-05-State-Before-Reconciliation]]. Старі кандидати, числові заміри й деталі доставок залишаються там та в датованих Fix/Audit; вони не є новими твердженнями про поточний PR або встановлену збірку.
