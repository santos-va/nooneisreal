Збереження сюжетів окремі від економіки й NPC. Пошкоджені байти не перезаписуються, незбережене завершення не створює стійку NPC пам’ять. Відсутній, пошкоджений або незавершений попередник призупиняє другий епізод без втрати його збережених фактів. Один вибір керує сюжетною карткою й напрямком; ручний вибір доручення та вимкнення guide збережені. Огляд предметів перевіряє фізичну дальність, видимість і власника UI; копіювання додатково перевіряє справжній промінь ліхтаря.

**Остання вже виконана перевірка:** перед PR #181 official Godot 4.7 дав smoke **164/19847**, gates **116 GDS/0**, **175 assets**, playable **85 сценаріїв/0**, усі rc0. До/після незмінні 793 source files, digest `0beea2abbfde9b603487a1c8aa3084f0337d3e842ab0d772d701789e09b6b32c`. Прийнято 21 фінальний native кадр нового епізоду та окремий доступний через клавіатуру журнал призупинення. Raw і точні межі — [[2026-10-05-Lower-Mark-Logic]], [[2026-10-05-Lower-Mark-Review]], [[2026-10-05-Lower-Mark-Visual]]. У цій звірці документації гру й батарею повторно не запускали.

**Доставка й апаратні межі:** є universal macOS export, installer та updater із перевіркою revision/hash і довантаженням змінених блоків; поточні команди — [[Build-and-Run]] та [[Export-Platforms]]. У [CI змердженого PR #180](https://github.com/santos-va/nooneisreal/actions/runs/37297997177) успішно завершилися docs gates, Godot smoke/playable/native compatibility та updater safety на macOS і Ubuntu; T1 особисто звірив jobs. Це hosted macOS regression, не встановлення на Santos M3. Наявність цих засобів і CI не доводить оновлення встановленого застосунку Santos. Його приймання попереднього зрізу на M3 не є виміром FPS/frame-time нового commit. Retina, фізичний контролер, звук, остаточний арт і нова Mac-збірка потребують свого приймання; реальні Santos Soundtracks ще не надані. Linux native використовує llvmpipe, а постановка на станції для кадрів не замінює суцільного ручного проходження.

Повний стан до цієї звірки збережено без зміни байтів у [[Handoff/2026-10-05-State-Before-Reconciliation]]. Старі кандидати, числові заміри й деталі доставок залишаються там та в датованих Fix/Audit; вони не є новими твердженнями про поточний PR або встановлену збірку.
