Збереження сюжетів окремі від економіки й NPC. Пошкоджені байти не перезаписуються, незбережене завершення не створює стійку NPC пам’ять. Відсутній, пошкоджений або незавершений попередник призупиняє другий епізод без втрати його збережених фактів. Один вибір керує сюжетною карткою й напрямком; ручний вибір доручення та вимкнення guide збережені. Огляд предметів перевіряє фізичну дальність, видимість і власника UI; копіювання додатково перевіряє справжній промінь ліхтаря.
