# 2026-10-04 — стійка Choko та передача меча

**Хто:** Santos · T1 Дедал · T2 Гефест (стійка, механіка, зброя) · T5 Арес · T4 Феміда · T7 Кліо.
**Контекст:** Santos попросив виправити неприродну стійку Choko, повернути видиму зброю та перекладання між руками. [[Plans/2026-10-04-Choko-Stance-Sword|План]] approved; реалізацію завершено, технічне приймання GREEN на `codex/choko-stance-sword`, залежній від відкритого [PR #167](https://github.com/santos-va/nooneisreal/pull/167).

## Що обговорили й вирішили

- Santos підтвердив один активний меч і V/R3. SOLO V, SHARED H/P; це передача зброї, не нова ульта. Права рука початкова; вільна рука б'є кулаком, ноги лишаються ногами.
- Канон [[Choko]] розрізняє смарагдову шуку й золотий кристальний варіант ульти. PNG є референсами, не готовими weapon GLB. Обрано процедурний об'ємний клинок як перевірну основу без платної генерації.
- Повний R8-аудит — у плані. Для стійки нижчу асиметричну позу обрано замість зміни камери або купівлі паку; для зброї стан руки з видимим handoff — замість статичного правого кріплення або двох мечів; для меша процедурну геометрію — замість плоскої PNG або платної генерації.
- Розглянуто нападника, захисника, ліворукий режим, геймпадне керування камерою, повернення з паузи, окремий характер Skea й конфлікт із гарпуном. Мірила — видимий контакт, одна зброя, зрозумілий клинок/кулак і відсутність прихованого посилення hitbox/damage.
- T5 визначає правила у [[02-Combat-System]] та [[03-Skills-Framework]]. Робочі 24 кадри передачі / контакт на 12 — **PLACEHOLDER**, передані координатором для реалізації та перевірки, не вимір природності. Докладні переривання й сумісність дій не дублюються у картці персонажа.
- T7 оновила [[Choko]]: застарілі light/heavy-кнопки замінено покажчиком на кінцівки й чинні профілі; спектральну ульту/256 замінено посиланням на золотий кристальний контракт; прибрано хибне «`.tres` ще Chrono Guard» після читання `passive_id = "printer"`.

## Приймання й відкрите

Реалізацію **прийнято в перевіреному технічному обсязі**: кінцеві `make check-playable` і `make gates` зелені, T4 дав GREEN без відкритих блокерів. Суб’єктивне приймання та фізичні пристрої лишаються відкритими. Native actual-input повтор завершено, докази нижче. Особливо: переривання до/після контакту, пауза й hitstop, reset, взаємовиключення з гарпуном/скілами, відсутність регресії Skea та стоп.

Godot запускає лише координатор послідовно. Попередній PR #167 не доводить якість нового зрізу. Mac M3 й фізичний контролер не перевірені хмарою. Новий PR має явно залежати від #167; main мерджить Santos.

За оглядом T1 прийнято фінальну ліву стійку та передачу в обох напрямках. Раніші невдалі native/pose версії **не є прийманням**; число кадрів саме по собі не доводить природності.

T7 прочитала завершальні маркери `check-playable-final.log`: **164 smoke-перевірки за 19824 кадри; 32 сценарії, 0 збоїв**. T1 підтвердив rc=0. Прочитаний `gates-final.log` завершується «БАТАРЕЯ ЗЕЛЕНА»: 59 GDS, 0 помилок парсингу; T1 підтвердив rc=0. [[Audit/2026-10-04-Choko-Stance-Sword|Фінальний вердикт T4]] — **GREEN у перевіреному технічному обсязі, відкритих блокерів немає**. Новий PR та його CI ще очікуються.

Передача готується як залежний PR поверх відкритого #167: опис має відділяти нову стійку й меч від уже перевіреної основи руху/гарпуна. `main` не змінювався.
