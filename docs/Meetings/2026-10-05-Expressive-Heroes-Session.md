# 2026-10-05 — Обличчя, матеріали та бойовка

**Хто:** Santos, T1 Дедал, T2 смуги face/materials/combat, T3 Архімед, T5 Арес, T6 Аполлон, T4 Феміда.

## Доручення

Santos вказав на слабкі текстури, емоції/вираз обличчя й загальний вигляд моделей; попросив оновити бойовку. Старіший двигун дозволено розглянути, якщо це реально відкриє потрібні інструменти й збереже гру.

## Рішення

- Перевірений паркур збережено локальним checkpoint `94a09a6`; нова гілка `codex/character-expression-combat`, без push. Повний game/tools manifest збігається з прийнятим 79/0.
- [[2026-10-05-Expressive-Heroes-And-Combat]]: зберегти ідентичність героїв, поліпшити матеріали й додати контрольовану міміку; окремо виправити втрату combo input під hitstop та відновлення захисту.
- User request авторизує видимі gameplay/visual правки. Damage/frame data без потреби не змінюємо; поточний стиль бою збережено. Необов'язкове уточнення щодо бажаного акценту надіслано користувачу.
- Огляд GLB виявив відсутність facial bones/morph targets. [[2026-10-05-Hero-Tools-And-Engine-Compatibility]] перевірив API міміки, retargeting, LimboAI і Godot Jolt: необхідного інструмента, який вимагав би відкату, не знайдено. Зберігаємо Godot 4.7 і чинний Mac pipeline; сторонні addons не встановлювалися.
- Цільова бойова смуга пройшла 160 перевірок і суміжні сценарії. Це проміжний scoped результат, не приймання всього нового дерева. Перші native face/material candidates відхилено через неповне закриття очей і залишкові білі ділянки тканини; уточнюються фактичні UV/skin межі, без зміни оригінальних GLB.

## Приймання

T1 особисто порівняв native baseline, відхилені candidates та `head-domain/`: неперервний захист голови прибрав внутрішні фрагменти outline, обидві повіки Choko закриваються, mouth Skea змінюється для hurt/KO. T6 незалежно прийняв поверхневі вирази та локальне поліпшення тканини. Частина білих marks грудей/верхнього плеча Skea збережена; повного перемальовування атласу чи анатомічного facial rig не заявляємо.

Focused raw: combat **160/0**, face **1734/0**, gear **7946/0**. Матеріальний on/off proof містить **29 159** незмінених захищених pixels у вказаних областях одного набору поз; це не доказ для всіх можливих ракурсів. Фінальний native — **156 PNG**, rc0, 280 code/resource hashes незмінні; 5-секундне демо особисто перевірено T1 через raw кадри, sheet і ffprobe.

Незалежні `make check` і `make gates` зелені: **112 GDS / 0**, smoke **164 / 19 847 кадрів**, **175/175 assets**. Root виконав повний playable: **81 сценарій / 0 failures**, rc0; усі 81 raw-журнали без неочікуваних errors/warnings/leaks. **779** game/tools файлів незмінні між T4 post-import і фінальним прогоном, digest `916816f998abde2b91315cbdf77092b16918c792cae6dfc19942f38e6bd8339b`. Три незалежні mutation controls спрацювали на змістовних порушеннях.
