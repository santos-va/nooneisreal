# 2026-10-03 — UX головного меню з даху (М1) і вибору персонажа (В1)

**Хто:** Santos · T8 Гермес
**Контекст:** issue santos-va/nooneisreal#5 (М1) — контракт лейауту меню поверх 3D-діорами для М3 Гефеста; заразом В1 з #11.

## Що обговорили
- Звідки беруться числа: база 1600×900 `canvas_items` + `expand` (`game/project.godot`), масштаб `s = min(W/1600, H/900)`;
  правила тексту/тачу/safe area — [[2026-10-02-Grapple-Input-UI]] § 4; контраст — пораховано python у сесії.
- Де пункти не заважають: ліва ¼ — край хмарочоса (старт прольоту), верх — коридор прольоту, низ-центр — вулиці.

## Що вирішили
- Плашка меню — **праворуч**: 16:9 x 0.71–0.95 · y 0.34–0.86; 21:9 x 0.78–0.96; ширина 384 од., поле 80 од. (5 %).
  Коридор прольоту 16:9 x 0.18–0.68 · y 0.05–0.50, зазор до плашки ≥ 0.03 ширини. Ліворуч — лише дзеркалом усієї діорами.
- Фокус — кислотно-жовта заливка (hex PLACEHOLDER для Аполлона); теракота як фокус відкинута (2.70:1 над світлим тлом).
- Пункти після В3: FIGHT · VERSUS · TRAINING · SETTINGS · QUIT.
- «Менше руху» → `user://settings.cfg` `[accessibility] reduce_motion`; масштаб UI → `[display] ui_scale`.
- Звук прольоту −6 дБ від музики меню — PLACEHOLDER; музики меню в репо ще нема.
- Вибір персонажа: картки P1/P2 по краях, сітка внизу по центру, проліт на цьому екрані вимкнено, курсори — через дії `p1_*`/`p2_*`.
- Усе — у [[06-UI-UX]].

## Що відклали / відкриті питання
- Пороги WCAG 4.5:1 / 3:1 і ТБ 5 % — без URL (`w3.org` заблоковано з хмари) → бриф Архімеду.
- Вбудовані `ui_*` Godot 4.7 і enum `handheld/orientation=4` — не перевірено (Godot у контейнері нема).
- 32:9 — outpaint M2-D або пілларбокс.
- Шрифт меню — не обрано (рядок у [[Textures-Registry]] із ліцензією).
