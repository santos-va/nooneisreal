## Перевірка

Перший інтеграційний прогін знайшов 2 очікування миттєвої пози в idle regression. Перевірка тепер чекає лише обмежений перехід і зберігає порівняння з чистим незалежним skeleton. Фінальний Godot 4.7.0 (`5b4e0cb0f`) `make check-playable` завершився rc0: smoke **164 checks / 19847 frames**, **50 сценаріїв / 0 провалів**, імпорт і парсинг 80 GDScript без помилок. Лог `/tmp/nir-validation/check-playable-final.log`, деталізація `/tmp/nir-validation/playable-final/`.

`python3 tools/distribution/test_distribution.py`: **24 tests / OK** (Linux із macOS mocks). Native CityStyle на Godot 4.7/Xvfb/Mesa llvmpipe: **26 checks / 0 failures**, `/tmp/nir-art-style.log`; це Linux software renderer, не M3. Зовнішній Godot завантажено з офіційного релізу й звірено SHA512. Перший import без socket-доступу мав sandbox ERROR; фінальний прогін із дозволеним socket-доступом чистий. Перевірка встановленої гри в Applications і native M3 у Linux не виконуються.

`make gates`: **БАТАРЕЯ ЗЕЛЕНА**, 80 GDScript / 0 parser errors; реєстр 174/174, wikilinks без битих цілей. Лог `/tmp/nir-validation/gates-final.log`.
