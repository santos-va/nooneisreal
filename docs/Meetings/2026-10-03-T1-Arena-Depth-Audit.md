## Blender — як під'єднати (перевірено в цій сесії, що відкрилось)

- **Офіційний коннектор Blender для Claude є:** сторінка `claude.com/connectors/blender` (відкрито) — «Created by Blender
  Lab», «verified by Anthropic», потрібен аддон, інструкція — `lab.blender.org/mcp-server/#addon`. Сайти blender.org з хмари
  закриті проксі (`EGRESS_BLOCKED`) — інструкцію там T1 не читав.
- **Спільнотний варіант** `mcp-for-blender` (раніше `blender-mcp`, github `ahujasid`, MIT, відкрито): `brew install uv`,
  `uvx mcp-for-blender install-addon`, у Claude Code — `claude mcp add blender uvx mcp-for-blender`; сокет `localhost:9876`;
  інструмент `execute_blender_code` виконує будь-який Python — **зберігай файл перед кожною командою**.
- **Не перевірено:** мінімальна версія Blender для офіційного (джерела з пошуку кажуть то 4.2, то 5.1), точний шлях у
  меню Claude Desktop (з пошуку: Customize → Connectors → Blender).
- **Хмарна сесія (як ця) до Blender на Mac не дістане** — аддон слухає лише локальний сокет. Працює Claude Desktop або
  Claude Code, запущений на тому ж Mac.
- **«Домальовувати текстури»:** Claude керує Blender через Python — матеріали, запікання, проєкція готових картинок
  Higgsfield, палітри, масштаб, експорт glTF; пензлем «від руки» він не малює.
- **Перші справжні задачі для Blender у нас:** (а) застосувати масштаб арматури героя Meshy (0.01) — тоді регдол може
  стати на героя напряму; (б) звести масштаб пропів MegaKit/KayKit; (в) перефарбувати палітри паків і перевірити контур
  `#2B2230`. **Скіл** `blender-cel` пише Аполлон **після** 2–3 реальних сесій — з того, що спрацювало, а не наперед.
