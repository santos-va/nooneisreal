# 2026-10-04 — Mac-застосунок та автоматичні оновлення

**Хто:** Santos · T1 Дедал · T8 платформа · T2 збірка · T6 арт · T4 аудит.
**Контекст:** запускати гру звичайним застосунком у Applications на MacBook Air M3.

## Що обговорили

Santos замовив standalone застосунок і оновлення після кожного мерджу, підтвердив
MacBook Air M3 та Applications. Лого: обличчя Choko по центру, легка усмішка,
поворот і погляд ліворуч, без погляду в камеру.

## Що вирішили

Маршрут — [[2026-10-04-Mac-App-Updates]]. Після успішних перевірок main збирається
macOS release; локальний updater перевіряє checksum, не перериває запущену гру,
не торкається user data. Перший installer має підтримати вже запаковану гру,
не вимагати редактора Godot або Python. main мерджить Santos.

Higgsfield generation прямо дозволена запитом. Баланс перед генерацією4568.75,
оцінка0.25. Один job `6862c65f-2e2c-4287-b373-03607d7a6d36` завершився.
Reference — чинний Choko portrait job `b7032ada-4c55-4268-9adf-fde55d0e16ff`.
Ці числа — історичний preflight, не поточний баланс.

## Що відклали / відкриті питання

Хмарний Linux не є локальним Mac; інсталяція й живий запуск на M3 потребують
першого запуску installer користувачем. Cloud policy блокує CDN готової іконки;
Santos отримав інструкцію дозволити домен або прикріпити PNG. Не стверджувати,
що байти іконки вже включені, доки файл не отриманий.

## Перевірений результат

Офіційний Godot4.7 і шаблони перевірені SHA512. Реальний universal macOS export
містить arm64+x86_64, PCK, ad-hoc підпис і revision. `make check`:164 перевірки,
19847 кадрів; gates:80 GDS/0. Updater:14 штатних і8 незалежних сценаріїв,
T4 закрив знайдений обхід symlink-перевірки та перервану заміну. Звіт —
[[2026-10-04-Mac-App-Updates-Review]]. Native macOS CI налаштовано перед publish,
але ще не виконано; локальний Mac не встановлено. Портрет згенеровано й Santos
показав його в чаті, однак вкладення не надало завантажуваних байтів. Походження
та незавершена інтеграція — [[2026-10-04-Choko-App-Icon]].

## Уточнення: довантажувати новий мердж

Santos попросив спростити оновлення до довантаження нових змін. Перевірено
два реальні експорти: попередня повна поставка265941840 байтів; для порівняння
4MiB блоків87/96 незмінні, нові gzip-блоки22899761 байт. Це вимір саме цих
архівів, не обіцянка розміру довільного мерджу. Вбудований підпис змінює hash
цілого Mach-O, тому розділення лише за файлами не дає потрібного результату.

Реалізація T8: необов'язковий індекс блоків поряд із сумісним schema1 manifest;
нова збірка відновлюється у staging, локальні байти використовуються лише
після перевірки hash, мережа віддає відсутні блоки. Повний ZIP залишається
для першого встановлення та старого updater; працює перехід через пропущені
мерджі без залежності від проміжних патчів. Фактичний production reader уже
відновив усі7 файлів і modes двох реальних збірок точно:87 блоків локально,
9 завантажено, payload22906587 байтів + index14962 =22921549 байтів,
91.38% менше повного ZIP. SHA/байти: scratch/mac-delta-proof/verification.log.
Довіряємо саме точному відновленню підписаного bundle; native codesign/Linux
не змішуємо. Малий Enable Updates.command оновлює лише updater, реєструє його
для наявного застосунку без мережі й не вимагає повного повторного installer.

## Публічне завантаження малого updater

За прямим уточненням Santos потрібне браузерне посилання, бо workspace-посилання
не відкриваються в нього. Дозволений до публікації малий архів скопійовано без
змін у `downloads/NoOneIsReal-Updater.zip`: 6271 байт, SHA-256
`848c3ca6e15963dde18a970bad3b58ce4ff86f6e44c96a228e4fe2859cee7d5a`.
ZIP CRC та точну відповідність двох скриптів commit `a7033a5` перевірено.
Архів лише налаштовує updater для вже встановленої гри; не містить повного app.
Публікація йде у робочу гілку, main не змінюється.

## Виправлення першого встановлення

Santos навів реальну помилку `Install the game first with the full offline
installer`. Переданий updater не вирішував установлення відсутньої гри.
Замість повторення тієї самої команди готуємо один Terminal bootstrap:
локальна збірка конкретного Git SHA та встановлення повного app, потім
увімкнення updater. Користувач обрав Terminal із кореня свого проєкту;
Apple Developer credentials не запитуємо повторно. Жодних вимкнень Gatekeeper
чи рекурсивного очищення quarantine; існуючі checkout і saves зберігаються.
