# 2026-10-04 — Mac-застосунок та автоматичні оновлення

**Хто:** Santos · T1 Дедал · T8 платформа · T2 збірка · T6 арт · T4 аудит.
**Контекст:** запускати гру звичайним застосунком у Applications на MacBook Air M3.

## Що обговорили

Santos замовив standalone застосунок і оновлення після кожного мерджу, підтвердив
MacBook Air M3 та Applications. Лого: обличчя Choko по центру, легка усмішка,
поворот і погляд ліворуч, без погляду в камеру.

## Що вирішили

Маршрут — [[2026-10-04-Mac-App-Updates]]. Після успішних перевірок main збирається
macOS release; локальний updater перевіряє checksum, не перериває запущену гру,
не торкається user data. Перший installer має підтримати вже запаковану гру,
не вимагати редактора Godot або Python. main мерджить Santos.

Higgsfield generation прямо дозволена запитом. Баланс перед генерацією4568.75,
оцінка0.25. Один job `6862c65f-2e2c-4287-b373-03607d7a6d36` завершився.
Reference — чинний Choko portrait job `b7032ada-4c55-4268-9adf-fde55d0e16ff`.
Ці числа — історичний preflight, не поточний баланс.

## Що відклали / відкриті питання

Хмарний Linux не є локальним Mac; інсталяція й живий запуск на M3 потребують
першого запуску installer користувачем. Cloud policy блокує CDN готової іконки;
Santos отримав інструкцію дозволити домен або прикріпити PNG. Не стверджувати,
що байти іконки вже включені, доки файл не отриманий.

## Перевірений результат

Офіційний Godot4.7 і шаблони перевірені SHA512. Реальний universal macOS export
містить arm64+x86_64, PCK, ad-hoc підпис і revision. `make check`:164 перевірки,
19847 кадрів; gates:80 GDS/0. Updater:14 штатних і8 незалежних сценаріїв,
T4 закрив знайдений обхід symlink-перевірки та перервану заміну. Звіт —
[[2026-10-04-Mac-App-Updates-Review]]. Native macOS CI налаштовано перед publish,
але ще не виконано; локальний Mac не встановлено. Портрет згенеровано й Santos
показав його в чаті, однак вкладення не надало завантажуваних байтів. Походження
та незавершена інтеграція — [[2026-10-04-Choko-App-Icon]].
