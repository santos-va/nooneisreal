# 05 — Платформи та інпут

Власник: T8 Гермес. Звірено 2026-10-04 з реалізацією PR #172 та cleanup PR #171.
Чинна мапа складається з `game/project.godot` та `game/scripts/core/InputRouter.gd`:
роутер перебудовує клавіатурні профілі й маршрутизує акорди геймпада. Самого
`[input]` недостатньо. Ця сторінка описує реалізацію, а не старі ТЗ запусків.

## Клавіатура — чинний 3D-режим

| Дія | SOLO P1 | SHARED P1 | SHARED P2 |
|---|---|---|---|
| Рух у площині камери | WASD | WASD | стрілки |
| Стрибок / підтягування на мотузці | Space | Space | / |
| Присід | X | X | M |
| Ліва рука | J | F | K |
| Права рука | K | G | L |
| Ліва нога | M | Z | N |
| Права нога | фізична кома | B | J |
| Блок, утримувати | L або F | LShift | RShift |
| Ухилення + напрям, stamina | LShift | C | . |
| Окремий dash-скіл + напрям | LAlt | LAlt | RAlt |
| Відчепитися від мотузки | Z | LCtrl | RCtrl |
| Розмова з NPC | G | Y | backslash |
| Скіл 1 / скіл 2 | U або R / I або T | Q / E | ; / ' |
| Гарпун у ворога / паркур | Q / E | T / R | O / I |
| Ультимейт | O або C | V | фізична кома |
| Меч Choko: дістати / змінити | V | H | P |
| Пауза | Esc | Esc | Esc |

SOLO додатково дає LMB/MMB для лівої/правої руки та Mouse4/Mouse5 для лівої/правої ноги. J/K/M/кома лишаються доступними: бічні кнопки миші не обов’язкові. RMB лишається оглядом; у SHARED mouse aliases вимкнені.

SOLO не призначає клавіатуру P2: другий боєць — CPU або геймпад device 1.
Кома — фізична клавіша `, (<)` на англійській розкладці, не стрілка ←.
Профіль зберігається в `user://settings.cfg`; він перемикається в меню KEYBOARD.
Tab показує хітбокси; Backspace скидає позиції в тренуванні.

У **2.5D** горизонтальний рух лишається A/D або ←/→; W/↑ дублює стрибок,
S/↓ означає присід, X/M більше не присід. Інші бойові прив'язки ті самі.
MODE перемикає площину/3D та відразу перебудовує мапу.

## Геймпад

Device 0 керує P1, device 1 — P2. Меню приймає обидва контролери.
Назви нижче — маршрути `InputRouter.binding_label`, не підтвердження
сертифікованого консольного порту чи живого приймання кожної моделі контролера.

| Дія | Xbox / PlayStation |
|---|---|
| Рух | лівий стік; D-pad ←/→ також рухають горизонтально |
| Стрибок / підтягування на мотузці | A / Cross |
| Присід | D-pad ↓ |
| Ухилення + напрям, stamina | X / Square + лівий стік |
| Окремий dash-скіл + напрям | Y / Triangle + X / Square + лівий стік |
| Блок, утримувати; відчеплення під час підвісу | B / Circle |
| Розмова з NPC | Y / Triangle + D-pad ↓ |
| Ліва / права рука | LB / L1 · RB / R1 |
| Ліва / права нога | LT / L2 · RT / R2 |
| Скіл 1 / скіл 2 | Y / Triangle + LB / L1 · Y / Triangle + RB / R1 |
| Паркурний гарпун / гарпун у ворога | L3 або Y / Triangle + LT / L2 · Y / Triangle + RT / R2 |
| Ультимейт | D-pad ↑ |
| Меч Choko: дістати / змінити | R3, натискання правого стіка |
| Огляд у solo / місті | правий стік |
| Пауза | Menu / Options |

У площині нахил лівого стіка вниз також дає присід; у 3D він означає рух.
Y фіксує дію на **свіжому натисканні** плеча/тригера, X або D-pad ↓. B має єдину дію `block` у InputMap; Fighter трактує її як відчеплення лише в GRAPPLE. L3 — короткий тап паркуру, який лишає правий палець на стіку огляду. Зміна Y при затиснутому
тригері не запускає іншої дії: спершу відпустити тригер. Аналоговий тригер має
гістерезис `TRIGGER_PRESS` / `TRIGGER_RELEASE`; значення в коді — PLACEHOLDER UX.
Клавіатура не залежить від модифікатора геймпада.

## Рух, огляд та ізоляція меню

Рух людини в 3D відносний до камери, а не до ворога. Утримуваний W/стік
використовує **поточний базис кожного фізичного такту**; після повороту камери
не потрібно відпускати напрям. Старий контракт «зафіксувати світовий напрям до
нейтралі» скасовано. `DuelFrame.human_to_world` і `InputRouter.view_basis` відділяють
намір руху від орієнтації тіла під час атаки. CPU має окремий шлях вводу.

У solo огляд: права кнопка миші + перетягування або правий стік. Бойова камера
плавно повертає ручне відхилення; міська зберігає обраний ракурс. Правий стік
огляду та R3 для меча — окремі дії. Мертва зона огляду `LOOK_DEADZONE = 0.2`
в `InputRouter.gd` — PLACEHOLDER UX. Наведення фіксує світовий промінь на момент
запиту пострілу; підказка цілі не гарантує влучання. Записаний пакет replay має
пріоритет над живим адаптером.

Меню, пауза й вкладена панель налаштувань володіють окремими блокуваннями
вводу. Вони очищають буфер; після виходу утримані кнопки та стік мають повернутися
до нейтралі. Подія закриття меню не стає бойовою атакою. Зміна профілю й
від'єднання контролера також очищають відповідний стан.

## Гарпун і меч — значення дій

- Паркурний гарпун чіпляється після фактичного контакту й залишається зачепленим
  після відпускання кнопки. Повторний тап паркуру, спрямований на наступну опору,
  запускає перехід; стару мотузку можна використати знову.
- Утримання стрибка вкорочує мотузку на обмежену відстань. Ходьба для
  підтягування не потрібна; бічний рух кермує маятником. Відчеплення — окрема
  клавіша Z / Ctrl за профілем, B на pad або ухилення; натискання блока під час
  підвісу також відчіплює. Ворожий гарпун зберігає hold/release семантику.
- GRAB ROPE означає повторний захват наявної мотузки, без нового пострілу.
  PREPARE GRAB показує ранню готовність; зачеплення відбудеться лише за
  фактичної досяжності мотузки. Підказка не обіцяє миттєвого захвату здалеку.
- Запас Choko 7 / Skea 2, без таймерного поповнення; промах змотується й повертає
  слот. Витягання з ворога повертає гарпун. Розвішені мотузки можна повторно
  використовувати; дубль зайнятого якоря не витрачає новий слот. Мотузки живуть
  між раундами матчу та очищаються на rematch. Правила — [[04-Grapple-System]].
- `weapon_swap` спершу дістає меч Choko зі спини; наступні натискання змінюють
  руку й форму через розпад/збирання. Доступно на землі в IDLE/WALK, без зайнятого
  гарпуна. Нога чи деш перериває анімацію; заблоковані дії не виконуються пізніше.
  Поточна реалізація також дістає меч при відповідній мечовій атаці: V не є
  обов'язковим замком усіх ударів. Анімація й баланс ще потребують приймання.

Чотири кінцівки реалізовано. `light`, `heavy` та старий `grapple` залишаються
програмними шляхами для CPU/сценаріїв, без дублювання фізичних бойових кнопок.
Ліміти дешів, комбінації та бойові числа — [[02-Combat-System]], [[03-Skills-Framework]].

## Місто

EXPLORE CITY запускає обраного P1 з тимчасовими **SOLO + 3D**. Після виходу
відновлюються попередні профіль і режим. Рух, огляд, стрибок, удари, меч, ухилення, окремий dash-скіл
і паркур доступні; скіли, ульти та гарпун у ворога в місті вимкнені. Пауза
містить довідку, пропуск навчальних підказок, перезапуск і повернення в меню.
Біля NPC дія interact відкриває локальну розмову; вона володіє блокуванням бойового вводу.
Камера при погляді вгору зсувається до плеча, зберігаючи бічну й поздовжню перевірки колізій.
Це прохідний прототип кварталу, не завершена кампанія; [[ADR-023-City-First-Exploration]].

### Міський паркур: уточнення 2026-10-05

Наявна дія `jump` також керує контактом із краями. У повітрі утримувати
Space / A (Cross) і рухатися до доступного краю, щоб повиснути. Для підйому
потрібно відпустити jump і натиснути знову: утримання, з яким герой схопився,
не запускає автоматичного підйому. `grapple_detach`, блок або присід відпускають
край. Для Skea утримання jump із рухом у стіну дає короткі стінні кроки;
відпускання jump або напряму завершує їх. Нових дій чи клавіш немає.

Міський HUD показує контекстні підказки через `InputRouter.binding_label`
за останнім пристроєм у `HarpoonAim`. Межа підтягування мотузки має окремий
напис `REEL LIMIT`: утримання jump не означає необмеженого підйому до якоря.
Після досягнення межі мотузка лишається зачепленою, доступні кермування,
перехід на іншу ціль і відчеплення. [[2026-10-05-Responsive-Parkour]].

### Відскок і перекат: доповнення 2026-10-05

У міському режимі обидва герої можуть один раз за повітряний цикл
відштовхнутися від справжньої вертикальної стіни. Спершу відпустити jump,
потім спрямувати рух **від стіни** й натиснути jump знову. Це також
доступно з висіння на краю; відпускання завершує стінні кроки Skea,
після чого новий jump із напрямом від стіни запускає відскок. Саме
утримання jump повторних відскоків не дає.

Для перекату після достатньо швидкого падіння утримувати чинний crouch
і напрям до приземлення на широку рівну опору: у SOLO це **X**, на
геймпаді **D-pad ↓** разом із лівим стіком. Відпускання crouch припиняє
перекат. Перекат не додає швидкості чи невразливості; поза не зменшує
фізичної капсули для проходу під перешкодами. Нових input actions немає.
Параметри й фізичні обмеження — [[2026-10-05-City-Parkour-Tricks]],
scope і приймання — [[2026-10-05-Parkour-Tricks-And-Quality]].

## Платформи й відкрите приймання

Пріоритет: PC/Mac клавіатура → геймпад → PS5/Xbox через W4 Consoles → Android/iOS.
Пресети експорту й перевірки вводу не означають готовий порт. MacBook Air M3,
Retina, фізичні контролери, тривала зручність і keyboard rollover ще потребують
живої перевірки; старі припущення про Apple-клавіатури не є виміром.

Майбутнє: повний ремап, автоматичні гліфи останнього пристрою, safe area та
тач із чотирма кінцівками й усіма скілами. Старий тач-ескіз light/heavy потребує
перепроєктування під поточний мувсет. Розміри кнопок і межі читабельності —
PLACEHOLDER до дослідження й тесту на пристрої; пакети гліфів не оголошуються
доданими без рядка в [[Textures-Registry]]. Історичні рішення зберігають датовані
плани/журнали нижче; старі таблиці не є чинними призначеннями.
