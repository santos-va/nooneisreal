# 06 — UI/UX: меню і HUD

Власник: T8 Гермес; скіл `game-ui-design`. Поточний HUD/меню — код у `game/scripts/ui/`.

## Принципи (з розбору SF6, Strive, P4A, DBFZ)

1. **Усі ресурси гравця — на одній фіксованій горизонтальній смузі.** HP, піпси раундів, метр,
   заряди гарпуна, кулдауни. Око не бігає; індикатори **не рухаються** під час бою.
2. **Прості плашки на складному фоні.** Kronshift деталізований → смуги пласкі, з косим зрізом.
3. **Текст ≥ 20–22 px при 1080p** для критичного; масштаб UI 100–200 %.
4. **Тач-цілі 44–48 dp, відступ 8 dp**, у дузі великого пальця.
5. **Піпси раундів — дискретні позначки**, не серця.

## Нестандартне, але зручне (напрям)

- Меню як «дошка розшуку» Kronshift: косі теракотові смуги, вирізки з карток персонажів на
  кислотно-жовтих плашках, чорнильні контури. Навігація — фокус (стрілки/стік), ←/→ перемикає
  варіанти без підменю.
- Вибір персонажа — сітка 2D (D-pad-дружня), картка персонажа праворуч із 3 панелями скілів.
- Анонси («ROUND 1», «K.O.») — брашовий леттеринг, як назва на картці.
- Тренування: лічильник кадрів, хітбокси (Tab), скидання (Backspace), override зарядів гарпуна.

## Що адаптується між пристроями

| | ПК | консоль/ТБ | мобільний |

| Розмір тексту | 100 % | 125 % | 100 %, великий x-height |
| Тач-лейаут | — | — | редактор |
