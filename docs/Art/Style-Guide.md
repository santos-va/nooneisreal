# Стайл-гайд

Власник: T6 Аполлон. Еталон — картки персонажів і фони Kronshift (Higgsfield, GPT Image 2.5).

## Форма

- **Чиста аніме-лінія, пласка cel-заливка**, 2–3 смуги світла, без градієнтів «3D-рендера».
- **Жирний чорнильний контур** силуету; внутрішні лінії тонші. У грі: inverted-hull/stencil outline
  (`shaders/outline.gdshader`, ширина 0.022) + toon-ramp (`shaders/toon.gdshader`, 3 смуги, тінь із синім тінтом).
- Руки — тільки кулаки або хват предмета, п'ять чітко окреслених пальців (повторюване правило промптів).

| роль | колір |

| HUD | тепла слонова кістка на темному; P1 жовтий, P2 м'ятний; метр — акцент бійця |
