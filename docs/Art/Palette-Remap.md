# Палітра-атласи паків → Sketch-Cel

**Власник:** T6 Аполлон · **Дата:** 2026-10-03 · **План:** [[2026-10-03-Santos-Packs-Arenas]] Ф3.1 (хвиля T6-0, пункт 0c)
**Статус:** чернетка до ключа стилю (хвиля T6-1). Hex може зсунутися після ключа — кожну зміну пишемо тут, з причиною.
**Кредитів:** 0. Інструмент: `tools/art/palette_remap.py` (`scan` · `render` · `derive` · `selftest`).

## Навіщо

Пак фарбує всі свої моделі **однією текстурою-атласом**: сітка плашок-градієнтів, кожна модель бере колір через UV.
Перефарбуємо атлас — і сотні моделей стають Cronshift за 0 кредитів, а наш `toon.gdshader` і контур `#2B2230` дають
решту стилю ([[ADR-007-Art-Style-Sketch-Cel]]). Одна таблиця = один стиль на весь пак, міняється за хвилину.

## Правила (однакові для кожного паку)

1. **Градієнт плющиться в одну пласку заливку.** У [[Style-Guide]] пласкі базові кольори й одна тінь. Градієнт у текстурі
   дав би «3D-рендер» (`NEG_ARENA`: «no 3D render look, no gradients»). Тінь дає шейдер, а не текстура.
2. **Тон — наш, світлота — паку.** Тон і насиченість беремо з [[Style-Guide]] або з канону річки `a2913501`
   (`stage_river_plate_v1.png`). Світлоту беремо з плашки паку: автор уже розвів нею частини моделі, стіна світліша за фундамент.
   Формула — `palette_remap.py derive --src <тон> --like <плашка паку> --sat-cap <стеля>`. Для латуні й моху, де джерело надто сіре,
   задаємо явні `--sat` / `--light`.
3. **Пропи тихіші за бійців.** Найнасиченіші плями в кадрі — Choko `#BD6133` (HSL s 57 %) і Skea `#5C2E80` (s 47 %).
   Для великих поверхонь пропів (камінь, підлога, дерево) стеля насиченості 10–40 %, для дрібних акцентів (прапори, їжа) — до 50 %,
   для латуні — 55 %. Тонів бійців в атласі немає: помаранчеве дерево паку стає вохрою, смарагд — оливою, фіолет — сливою.
4. **Смуга = колір своєї клітинки.** Вкладені смуги-канти жодна модель KayKit Dungeon не бере (`scan` → 0 вершин). Заливаємо їх
   кольором клітинки, щоб мип-рівні не підмішували в плашку чужий колір.
5. **Ніч — світлом, а не атласом.** Ніч у грі вмикає світло: `Arena.gd:26-34` бере `sun` / `ambient` зі `STAGES[*].night`
   (`GameState.gd:27-34`) і запалює ліхтарі (`Arena.gd:242`). Нічних текстур у бійців немає. Нічний атлас пропів затемнив би їх
   удруге й розвів би з бійцями. Тому атлас **один** на день і ніч, а колонки «ніч» у таблиці немає.
   Це відхилення від плану Ф3.1 («день і ніч»): у Ф3.2 Гефест робить один файл, а не два.
6. **Що світиться вночі — прапорець матеріалу, а не колір** (§ Емісія).

## KayKit Dungeon 1.1 EXTRA — `dungeon_texture.png`

Пак — гілка `textures/santos-pack`, `tools/packs/KayKit_Dungeon_Pack_1.1_EXTRA.zip`, CC0 ([[Textures-Registry]] § Паки-джерела).
Атлас 1024×1024, сітка 8×4, клітинка 128×256. Копії в `Assets/gltf/` і `Assets/textures/` збігаються попіксельно
(`ImageChops.difference(...).getbbox()` → `None`).

```
python3 tools/art/palette_remap.py scan --atlas <KayKit>/Assets/gltf/dungeon_texture.png --models <KayKit>/Assets/gltf
→ моделей: 283 · з цим атласом: 283 · вершин: 206793 · UV поза [0,1] (загорнуто): 0 · плашок: 40 · з вершинами: 21
```

### Емісія — ТЗ Гефесту (Ф3.3)

Полум'я бере ту саму плашку `r2c7`, що й монети: `torch_lit` → 29 вершин у `r2c7`, `candle_lit` → 29, `candle_thin_lit` → 29;
у `torch`, `candle`, `candle_thin` без `_lit` плашки `r2c7` немає (`model_uvs`, виміряно). Тому світіння не можна вмикати
на плашку для всіх. Матеріал моделей `*_lit` — окремий: `emission_texture` = маска (біле лише в `r2c7`, решта чорне),
колір емісії — `LAMP_LIGHT` (`Arena.gd:106`, `Color(1.0, 0.74, 0.42)`), вмикається вночі разом із ліхтарями. Монети й скрині лишаються на звичайному матеріалі.

### Як прогнати

```
python3 tools/art/palette_remap.py selftest
python3 tools/art/palette_remap.py render --atlas <KayKit>/Assets/gltf/dungeon_texture.png --models <KayKit>/Assets/gltf --strict --section "KayKit Dungeon" --map docs/Art/Palette-Remap.md --out <scratch>/kaykit_dungeon.png --board docs/assets/screenshots/2026-10-03-palette-remap-kaykit.png
```

`--strict` вимагає, щоб у таблиці була кожна плашка атласу. `--models` вимагає, щоб у ній була кожна плашка, яку беруть моделі.
Таблиця крива — нічого не записується, rc 1. Два прогони дають один і той самий файл (selftest це перевіряє).

Дошка «було / стало» — `docs/assets/screenshots/2026-10-03-palette-remap-kaykit.png`: ліворуч кожної пари плашка паку,
праворуч наша, на м'ятній плашці листів `#B8CBB1`.
