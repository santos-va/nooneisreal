## Порядок (щоб не перемальовувати двічі)

1. Лист поз Choko → Santos затверджує стиль на одному персонажі.
2. Те саме для Skea.
3. Turnaround + T-pose → 3D (найдорожче — лише після затвердження листів).
4. Предмети, тайли, іконки.
5. Арени: річка → базарчик → площа з фонтаном; потім VFX, UI.
