## Хвиля 2 — живий бій і пропи з паків

Хвиля 2 — це запуски 7–11 «живого бою» ([[2026-10-03-Living-Combat]]) і арени з паків Santos
([[2026-10-03-Santos-Packs-Arenas]]). Хто за що береться, розписано в [[2026-10-03-Wave-2-Kickoff]]. Нижче лише назви. Числа
й рішення лежать на сторінках, на які ведуть посилання.

| термін | значення |
|---|---|
| Хвиля 2 | Запуски 7 (живі тіла), 8 (акробатика), 9 (поверхні), 10 (ухили й стати), 11 (живе оточення). Порядок 7 → 11 Santos схвалив 2026-10-03 ([[2026-10-03-Living-Combat]]). |
| «Гравець — що, тіло — як» | Правило [[ADR-016-Player-Decides-What-Body-Decides-How]]. Удар, блок чи ухил з'являються лише з вводу гравця або CPU. Тіло саме вирішує тільки, як це виглядає: куди йде кінцівка, на якій висоті блок, як стоять ноги. |
| IK (інверсна кінематика) | Кінцівка тягнеться до точки, а поза суглобів рахується від неї. Це шар презентації: удар цілить у зону суперника (голова / корпус / ноги), блок стає на висоту атаки, ступні — на нерівне. Влучання вирішують дані, IK його лише показує ([[ADR-016-Player-Decides-What-Body-Decides-How]] п. 2–3). Вузли Godot 4.7 для IK — бриф Архімеда R4 ([[2026-10-03-Fight-Craft-Research]]). |
| Стат стійкості | Число в даних бійця. Проти сили удару воно вирішує, що буде: флінч, стагер чи нокдаун. Рішення детерміноване ([[ADR-016-Player-Decides-What-Body-Decides-How]] п. 4). Числа задає Арес у запуску 10, баланс — [[08-Balance]]. У коді його ще немає: `grep -rn "stagger\|poise\|stability" game/scripts` → лише коментар у `ArenaLayout.gd`. Схожий стат, що вже є, — `water_balance` у `CharacterData.gd`. |
| Флінч (flinch) | Найслабша реакція на удар: боєць лишається на ногах, тіло смикається залежно від зони удару (голова / корпус / ноги). Зараз це пружина в `RigAnimator` ([[Active-Ragdoll]]). |
| Стагер (stagger) | Середня реакція за статом стійкості: боєць хитається, але не падає. Кадри й поріг — **не визначено** (Арес, запуск 10). |
| Регдол на скелеті | Регдол із кісток моделі героя (`PhysicalBoneSimulator3D`) замість капсульних тіл `Ragdoll.gd`. Це стадія 2 у [[Active-Ragdoll]], крок 7.1 у T2·A. |
| Частковий регдол | Стадія 3 у [[Active-Ragdoll]]: фізика веде лише вдарену кінцівку і кілька кадрів тягне її назад до пози анімації. Числа — на тій сторінці. |
| Кінематична позиція після регдола | Варіант (а) з [[ADR-017-Post-Ragdoll-Position]]. Після запуску позицію бійця рахує траєкторія з даних удару (швидкість запуску й гравітація), а не таз регдола. Регдол лишається картинкою, а вставання відраховується кадрами. ADR **запропоновано**, чекає слова Santos. Без нього T2·A цього не чіпає. |
| Кадри з хмари | 2–4 скриншоти Godot під Xvfb, які додає кожен PR із видимою зміною, поки Santos не вдома. Вони лежать у `docs/assets/screenshots/` і мають підпис у [[Screenshots]]. Звук і клавіатуру з них не видно. |
| Контакт-лист паку | PNG-сітка всіх мешів паку з іменами: `docs/assets/screenshots/packs_*.png`, крок Ф0.3 Гефеста ([[2026-10-03-Santos-Packs-Arenas]]). Без нього пропи обирають наосліп, і каталог пропів чекає на нього. |
| Палітра-атлас | Одна текстура-сітка плашок кольору, з якої беруть колір усі моделі паку. У KayKit це 1024×1024, 8×4 плашки ([[2026-10-03-Santos-Packs-Arenas]]). Наш стиль на пропи накладає перефарбований атлас + `toon.gdshader` + контур. |
| Ключ стилю | Один кадр із паку, перемальований у Sketch-Cel з референсом канону річки. З нього береться палітра-ціль для перефарбування атласів (хвиля T6-1, кредити — лише зі словом Santos; [[2026-10-03-Santos-Packs-Arenas]]). |
