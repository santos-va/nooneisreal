# Глосарій

| термін | значення |
|---|---|
| Storm-look | Візуал Naruto Ultimate Ninja Storm: пласкі зони кольору, 2–3 смуги світла, чорнильний контур, мальовані фони. |
| Active ragdoll | Фізичне тіло, яке «м'язами» (пружини/PD-контролер) тягнеться до анімованої пози; Euphoria в Rockstar. |
| Hitstop | Заморозка обох бійців на N кадрів у момент влучання; продає вагу удару. |
| Startup / Active / Recovery | Кадри до появи хітбокса / кадри, коли хітбокс б'є / кадри після. 60 Гц. |
| Hitstun / Blockstun | Кадри, на які жертва втрачає контроль після влучання / після блоку. |
| Launcher | Удар, що відправляє жертву в політ → у прототипі в регдол. |
| Knockdown | Удар, що валить з ніг на місці (теж регдол). |
| Метр | Ресурс 0–100 за удари; 100 = ультимейт. |
| Гарпун (grapple) | Інвентарний гак: тап = зип до якоря, утримання = свінг, присід+гак = підтягнути ворога. 3 заряди, 3 с на заряд. |
| Якір (anchor) | `Marker3D` у групі `grapple_anchor` — ліхтар/балкон, куди чіпляється гак. |
| Push-box | Невидимий бокс, що не дає бійцям стояти один в одному; розводимо вручну. |
| Kronshift | Місто-сетинг: присмерк, теракота, сланцево-синій, бірюзові тіні, латунні дахи, ліхтарі. |
| Картка (card) | Лист персонажа на кислотно-жовтій плашці: 4 ракурси + 3 панелі скілів. |
| PLACEHOLDER | Позначка в даних: число не заземлене, замінити після інтерв'ю/тестів. |
| Сигнатурний рух | Слот кнопки деша, у кожного бійця свій: Choko — деш, Skea — Flash Step. |
| Flash Step | Телепорт-ривок Skea крізь суперника за 4 кадри, 3 заряди → 4.5 с; лишає привидів і рвані шматки. |
| Shaper | Тінь [[Skea]], викликана під час його прокляття: один із ворогів, що з'явився, бо Skea прокляли; на боці того, хто прокляв. Не ульта Skea. Skea найбільше прагне перерізати саме його — [[Lore]] § Прокляття і гримуар ∞8. |
| Слабка точка (мітка) | Фіолетове кільце на зоні суперника (низ/середина/верх); удар Skea туди — крит. |
| Armor Break | Статус: усі зони — слабкі точки на 4 с. |
| Крит | ×1.5 урону, ×3 чіп через блок, фіолетова іскра. |
| Afterimage (привид) | Напівпрозора копія пози, згасає ступенями (≈ 12 fps). |
| Перемотка (rewind) | RECORD Choko: повернення до маркера з частковим відновленням HP. |
| Ідеальний блок | Блок ≤ 8 кадрів до удару; у Choko заморожує нападника. |
| rc=2 | «Не зміг виміряти» у гейтах — блокує так само, як порушення. |
