# Choko (Чоко)

**Роль у команді:** головний герой, лідер. **Статус у грі:** боєць №1, кіт PLACEHOLDER.
**Картка:** `card_choko_v3.png` (Higgsfield, 2026-10-02 11:15, id `bcddbbc6`) — [[Textures-Registry]].

## Зовнішність (відновлено з промптів Higgsfield, 2026-09-30 → 10-02)

- Обличчя за фото-референсом Santos: худе вузьке лице, довгий прямий ніс, великі сіро-зелені очі;
  густе кучеряве темно-каштанове волосся, довше на 7–8 см, закриває скроні й вуха, без вибритих боків.
- **Кольчужна куртка** (v3): дрібні сталеві кільця (gunmetal) + приглушено-помаранчеві шкіряні панелі,
  тонка кремова смуга, високий комір, довгі рукави. Раніше — вітрівка burnt-orange (v2), темно-зелений плащ (v1).
- Штани сланцево-синьо-сірі; чорні шкіряні рукавички; **великий аналоговий годинник на лівому зап'ясті**.
- **Зброя:** меч-шука (пікоподібний), перефарбований у зелене: смарагдове лезо зі світлішою кромкою,
  темно-зелена обмотка, латунно-золота гарда. Раніше — два чорні лаковані віяла зі сталевими кігтями (v1–v2, скасовано).
- Вираз: збуджений, трохи нервовий.
