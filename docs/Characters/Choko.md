# Choko (Чоко)

**Роль у команді:** головний герой, лідер. **Статус у грі:** боєць №1, кіт реалізовано (числа PLACEHOLDER).
**Картка:** `card_choko_v3.png` (Higgsfield, 2026-10-02 11:15, id `bcddbbc6`) — [[Textures-Registry]] (заплановано, `tools/fetch_assets.sh`).
**Роль у бою:** контроль часу. Меч, перемотка, заморозка. Міцніший і повільніший за [[Skea]].

## Зовнішність (з промптів Higgsfield)

- Худе вузьке лице, довгий прямий ніс, сіро-зелені очі; густе кучеряве темно-каштанове волосся, закриває скроні.
- **Кольчужна куртка** (gunmetal-кільця + приглушено-помаранчеві шкіряні панелі, кремова смуга, високий комір).
- Сланцево-синьо-сірі штани, чорні рукавички, **великий аналоговий годинник на лівому зап'ясті**.
- **Зелений меч-шука**: смарагдове лезо, темно-зелена обмотка, латунна гарда.

**Палітра VFX:** смарагд `#33E68C` · хроно-блакитний `#99C7FF` · помаранч куртки `#BD6133`.
