# Налаштування комфорту — T2

Предмет: для всіх налаштувань звуку й тряски змінюється лише подача, а значення залишаються скінченними в межах 0–1.

`ComfortSettings` завантажується після `Sfx` і `UltMusic`: використовує їхні шини, не створює дублікати та не забирає компресор/лімітер SFX. Master, SFX і Music регулюють гучність шин; 0 вимикає шину. Налаштування тряски множить лише зміщення лінзи `CameraImpact` в обох камерах. Після чинних ефектів Master додається один `AudioEffectHardLimiter` з межею −1 dB, підсиленням 0 dB і release 0,1 с; повторна ініціалізація не дублює його. Це захист суми SFX+Music при 100% повзунках, а не підтверджений на слух мікс. API перевірено за [XML Godot 4.7](https://raw.githubusercontent.com/godotengine/godot/4.7-stable/doc/classes/AudioEffectHardLimiter.xml). Бойові дані, кадри, позиції, ввід не змінюються.

Початкові значення — Master 80%, SFX 80%, Music 60%, тряска 50%: стартове налаштування комфорту, не підтвердження слухового балансу. Панель передає зміни наживо, зберігає явно. `user://comfort.cfg` відокремлений від майбутніх прив'язок керування; невідомі секції та ключі зберігаються. Запис іде через тимчасовий файл і перейменування. Відсутній файл дає типові значення без запису; пошкоджений або недоступний файл блокує запис, щоб не знищити дані. Нескінченні/нечислові значення з файла замінюються типовими, скінченні обрізаються до 0–1.

## Перевірка

`godot --headless --path game -s "$PWD/tools/settings/comfort_check.gd"` — потрібен `COMFORT_CHECK_COMPLETE` з нулем помилок та код 0. Негативні форми: NaN/INF у API, хибні типи та діапазони файла, пошкоджений файл; додатково нульова гучність, незмінні ефекти й невідомі ключі. Запуск Godot виконує координатор послідовно з іншими сценаріями. Фінальний прогін координатора: 28 перевірок, 0 помилок, явний `EXPECTED_CORRUPT_CONFIG_REJECTED`; негативний контроль підтвердив точний `ERR_PARSE_ERROR`. Інтеграційний UI-сценарій перевірив обидві справжні камери: ненульовий імпульс при 100% та нульове зміщення при 0%. Загальний прогін: 164 перевірки бою, 19 сценаріїв регресії без провалів, гейти зелені. Діагностика парсера приглушена лише навколо навмисно пошкодженого тестового файла, попередній прапорець відновлюється відразу.
