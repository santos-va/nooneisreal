# Чотири кінцівки: фізичний ввід і модифікатор

**Дата:** 2026-10-04 · **Роль:** T2 Гефест · **Стан:** цільові тести координатора перевірено за журналами: limb input 124/0, comfort input 31/0; повна батарея й native UI ще очікуються.

За затвердженим [[Plans/2026-10-04-Free-Movement-Limbs]] і контрактом [[05-Platforms-Input]] додано `left_hand`, `right_hand`, `left_leg`, `right_leg`. SOLO використовує фізичні J/K/M/кому; SHARED — F/G/Z/B та K/L/N/J. Старі `light`/`heavy` збережено лише програмно для CPU та сценаріїв, їхні фізичні події вилучено.

Геймпадні LB/RB/LT/RT обробляються маршрутизатором джерел, а не дубльованими подіями InputMap. На початку натискання стан Y обирає звичайний удар або skill1/skill2/гарпун; Y+LT зарезервовано. Обраний маршрут зберігається до відпускання плеча/тригера. Пороги тригера 0.55/0.35 — параметри реалізації з гістерезисом, не числа бою. X утримує блок. Клавіатура й другий геймпад не успадковують чужий Y.

UI очищає буфер та активні маршрути, але пам’ятає фізичне утримання до нейтралі. Автолоад обробляє події також під час паузи, щоб бачити відпускання. Від’єднання геймпада скидає маршрути. Спільний `binding_label` формує клавіші й акорди у довідці; інтерфейс більше не показує прямий скіл на LT.

Предмет: для всіх підтримуваних джерел натискання породжує лише обраний на початку намір; зміна модифікатора та UI не породжують другий удар.

`tools/input/limb_input_check.gd` подає справжні InputEventKey/JoypadButton/JoypadMotion: усі чотири кінцівки обох пристроїв, профілі без конфліктів, натискання/відпускання Y на утриманні, зарезервований акорд, шум тригера, джерело клавіатури, pause/neutral, disconnect і legacy virtual CPU. Команда: Godot 4.7 `--headless --path game --script ../tools/input/limb_input_check.gd`; необхідні rc=0 та `LIMB_INPUT_COMPLETE ... failures=0`, без runtime error. При провалі — виправлення маршрутизатора або фактичної невідповідності тесту контракту, не послаблення гарда. Існуючий comfort-тест оновлено на нову семантику J.

Перевірено журнали `/workspace/nooneisreal-env/free-limbs/logs/limb_input_check.log` і `comfort_input_check.log`: Godot 4.7, 124/0 та 31/0, без runtime errors. Час журналу після останньої зміни тесту: включено paused input та disconnect.

Godot та повну батарею запускає тільки координатор, щоб не конфліктувати за імпорт і rendering workspace. Слухове/тактильне приймання реальним контролером на Mac цим тестом не заявлено.
