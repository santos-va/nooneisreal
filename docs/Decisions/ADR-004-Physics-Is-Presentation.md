# ADR-004 — Фізика ніколи не вирішує влучання

**Статус:** прийнято 2026-10-02.

## Рішення

Хітбокси/хартбокси — кінематичні запити на 60 Гц такті. Jolt (регдол, пропси) — лише презентація.
Бійці не стикаються фізикою; push-box розводиться вручну.

## Чому

Детермінізм (майбутній онлайн/rollback), однакова поведінка на всіх платформах, незалежність від
версій Jolt, читабельність бою як у Storm. Euphoria-ефект отримуємо на шарі презентації: спринг-флінч,
регдол із «м'язами», hitstop, камера.
