# ADR-009 — Розкладка SOLO: ліва рука рух, права рука дії

**Статус:** прийнято 2026-10-02 (Santos: «керування незручне»). Реалізація — фаза 1 плану.
Для вільного 3D-руху (`GameState.free_move`) — уточнення [[ADR-014-Free-Movement-Layout]] (прийнято 2026-10-03).

## Рішення

Дефолтний профіль клавіатури для P1 — **SOLO**: A/D/W/S/Space/LShift/E лівою, J/K/L/U/I/O правою
([[05-Platforms-Input]]). Старий розподіл «двоє на одній клавіатурі» лишається профілем **SHARED**.
Перемикач — у меню й у налаштуваннях, збереження в `user://settings.cfg`. Геймпад не змінюється.

## Чому

Зараз усі дії P1 на лівій половині (F/G/Q/E/R/C/V), а права рука вільна. Розкладка J-K-L + U-I-O — звичний
стандарт ПК-файтингів і платформерів (Brawlhalla та інші), домашній ряд, без ⌘ і Ctrl.

## Чим платимо

Профілі конфліктують (K/L/I зайняті P2 у SHARED), тому потрібен перемикач і InputMap, що будується в рантаймі.
