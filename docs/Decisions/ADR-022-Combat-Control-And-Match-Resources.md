# ADR-022 — екранний рух, ресурс ухилень і межа матчу

**Дата:** 2026-10-04 · **Автор:** T1 Дедал · **Статус:** прийнято в межах прямого доручення Santos; нові настроювані числа залишаються PLACEHOLDER до playtest.

## Контекст

Користувач повідомив інверсію «вперед», невагому мотузку, недостатню різницю комбінацій, телепортоподібний Skea dash та залишки мотузок після нового матчу. Аудит, три варіанти й шість поглядів — [[Plans/2026-10-04-Combat-Control]]. Новий запит уточнює контракти з [[Handoff/2026-10-04-Decisions-And-Validation]], не скасовуючи finite inventory, ручне наведення, чотири кінцівки й UI fences.

## Рішення

1. Людський рух екранний протягом усього утримання клавіш. Input adapter на такті фізики публікує актуальний горизонтальний view-basis; Fighter читає записуваний packet, а не Camera3D. Записаний playback не перезаписується live adapter. Старе правило «світовий напрям замкнений до нейтралі» більше не діє за наявності packet. CPU зберігає власний тактичний напрям.
2. Choko має п'ять ухилень, Skea три. Кожне використання витрачає заряд; відновлення після серії дорожчає зі збільшенням витраченого запасу. HUD показує залишок і фактичний час відпочинку. Стрибок+напрям+ривок Skea — одна видима дуга зі збереженням вертикального руху, не окремий teleport із втратою стрибка. Вісім напрямків визначаються екранним вводом.
3. Утримання jump/Space під час зачеплення виконує обмежену підтяжку. Гравітація, тангенціальне кермо, демпфування й обмеження швидкості дають контрольоване розгойдування. Корекція натягу не повинна створювати радіальну енергію. Фізично точна м'язова/канатна симуляція не заявляється.
4. Один фізичний anchor допускає один новий deployed rope за матч. Перевірка атомарна в registry при contact; програлий одночасний постріл повертається через чинний recovery, без втрати/подвоєння предмета. Уже залишеною мотузкою можуть користуватися обоє, без нового витрачання. Раунд зберігає registry, rematch/new match очищає його до reset бійців. Default first-to-two: два або три результативні раунди.
5. Комбінації лишаються обмеженими трьома normals із підтвердженням влучання; чергування рук/ніг отримує власну історію і різні завершення. Whiff/block не дає безумовного продовження. Донорська шкода не зростає через презентацію.
6. Choko починає з мечем за спиною. Чинна дія V/R3 (SHARED H/P) спершу дістає його, наступні перемикання використовують розпад/формування пилу; один активний меч. Форми — процедурна презентація, не приховані бонуси дальності/шкоди. Interrupt, snapshot руки й UI suppression зберігаються.
7. Skea під активною ультою має позу левітації зі схрещеними ногами/жестами до книги. Хвилі normals фіолетові й розширюють передню межу на близько1м, з єдиним авторитетним влучанням; вимкнення FX не змінює шкоду. Choko/Skea ult effects завершуються при KO/reset до можливого нового влучання; Skea додатково завершує ульту при чинному armor break. Запущений кристальний ефект Choko зберігає стару поведінку при звичайному hitstun. Beat data існуючих ульт зберігається.

## Приймання

Focused тести через strict playable runner, `make check-playable`, `make gates`; runtime errors і відсутні sentinels блокують. Окремо native кадри перевіряють читабельність, але не доводять комфорт/FPS на Mac. Межі й результати — [[2026-10-04-Combat-Control-Review]] та [[2026-10-04-T1-Combat-Control]].
