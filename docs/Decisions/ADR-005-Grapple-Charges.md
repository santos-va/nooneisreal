# ADR-005 — Гарпун: 3 заряди, 3 с на заряд, пауза під час свінгу

**Статус:** прийнято 2026-10-02 як дефолт; перемикач лишено. **Контекст:** [[2026-10-02-Grapple-Input-UI]].

## Рішення

- 3 заряди; **один заряд повертається кожні 3 с** (Tracer/Genshin-модель); під час тетера регенерація на паузі.
- `grapple_regen_all_at_once = true` вмикає початкову ідею Santos («3 підряд → 3 с → усі назад»).
- Без додаткового локауту на 0 зарядів. Відмова — звук і тряска піпсів.

## Чому

Повернення всіх трьох за 3 с робить гак майже безкоштовним рухом — суперник не отримує вікна.
Послідовна регенерація тримає гак ресурсом (9 с до повного) і читається по піпсах.
Остаточне слово — за відчуттям на Mac і відповіддю Santos в інтерв'ю.
