# ADR-010 — Місто називається Cronshift

**Статус:** прийнято 2026-10-03 (Santos: «напис Cronshift, ми замінемо, бо трохи помилка»).

## Рішення

Канонічна назва міста — **Cronshift**. Написання «Kronshift» у репо — помилка, його замінюємо всюди: текст
вікі, сторінка міста, код, імена ассетів, промпти. Неоновий напис на вежі арени `fountain` — **CRONSHIFT**.
