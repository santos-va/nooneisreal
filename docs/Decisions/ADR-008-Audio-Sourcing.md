# ADR-008 — Звук: безкоштовні бібліотеки + шарування, не генерація Higgsfield

**Статус:** прийнято 2026-10-02.

## Рішення

SFX ударів беремо з бібліотек з дозвільними ліцензіями: Sonniss GDC (royalty-free), Kenney (CC0),
Freesound CC0, OGA CC0. Збираємо їх шаруванням (свіст + транзієнт + тіло + саб) локальним скриптом
`tools/audio/build_sfx.sh` на ffmpeg. Кожен файл — у [[Textures-Registry]] з джерелом і ліцензією.
Голоси пізніше можна робити TTS у Higgsfield. Музику пишуть Santos із товаришем.

## Чому

- Інструменти Higgsfield для SFX і музики (`mirelo_text_to_audio`, `sonilo_music`) за власним описом —
  «тільки для game-pipeline», для окремого аудіо їх не можна (перевірено `models_explore`, R0).
- Професійні бібліотечні удари звучать «потужно» одразу. Синтез із шуму (теперішні 22 файли) — ні.

## Чим платимо

Ручне завантаження на Mac (сайти закриті для хмари) і догляд за ліцензіями в реєстрі.
