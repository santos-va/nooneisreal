# ADR-021 — Тонкий адаптер Codex над спільним законом

**Дата:** 2026-10-04 · **Автор:** T1 Дедал · **Статус:** запропоновано, технічний спосіб ще не прийнятий Santos.

## Контекст

Santos доручив зробити цей чат головним кріслом для важливих рішень і послідовностей рольових сесій. Handoff описує спільні state, constitution, roles і hooks. Аудит актуального `main` `1440344` та R8-порівняння — [[2026-10-04-Codex-Coworker]]. У executor є CLI `0.159.0-alpha.3`, але його native events, discovery та зв'язок із поверхнею цього чату ще не доведені.

## Пропозиція

Варіант B: root AGENTS явно маршрутизує Codex до окремого тонкого адаптера, рольові shims посилаються на shared bodies, reminders використовують shared hooks. Варіант A залишається явним ручним fallback; plugin C відкладено. Не заводити другу конституцію й не змінювати Claude adapter. Hook schema і discovery path обираються лише після inventory цільового runtime.

T1 планує й приймає звіти, T2 реалізує в окремій сесії, T4 незалежно перевіряє. Нове доручення Santos дозволяє планувати агентів і субагентів, але не скасовує рольову власність, R5, R6 чи потребу в окремих сесіях. Кредити й мердж лишаються за Santos. Реалізація на одній поверхні не означає встановлення на всіх.

## Наслідки й приймання

Менше дублювання правил, зате потрібні runtime-негативні контроли та окреме приймання кожної поверхні. Missing Godot не може давати повну зелену валідацію; зміна CI й strict gate — окремий атомарний PR. Детальні критерії, ≥3 варіанти, ≥5 поглядів та хендофи — у плані. Нинішній PR містить лише документи; інтеграція не оголошується готовою.
