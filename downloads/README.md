# Оновлення встановленої гри на Mac

`NoOneIsReal-Updater.zip` — маленький інсталятор **лише updater**, не повна гра.
Потрібен уже встановлений `/Applications/No One Is Real.app` із перевіреної збірки.

1. Завантажте й розпакуйте ZIP.
2. Відкрийте `Enable Updates.command`.
3. Нові перевірені main-збірки довантажуватимуть змінені блоки після закриття гри.

Налаштування updater не завантажує гру повторно. До публікації першого main-каналу
фонові перевірки чекатимуть на його появу. Повний застосунок цей архів не встановлює.
